### Objectives of the Course

The aim of this course is to learn microprocessor architectures, how to design the internal structure of a processor with hardware description languages.

### Course Content

Instruction set architecture (ISA), RISC and CISC architectures, assembly and machine language, addressing modes, branching and procedures. Computer arithmetic, arithmetic logic unit (ALU) design. Processor design, data path and control implementation, micro programmed control, interrupts. Pipelining, pipelined processor design. Memory hierarchy, caches, virtual memory. I/O devices, memory mapped I/O.
