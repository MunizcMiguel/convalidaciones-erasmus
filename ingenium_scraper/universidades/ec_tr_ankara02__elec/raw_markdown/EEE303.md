### Objectives of the Course

This course gives a brief introduction to a working understanding of basic computer organization, data representation, programming language constructs, and algorithmic thinking. It is designed as an advanced course in programming for EEM students, especially for use in graduation projects.

### Course Content

Introduction to Python; basic and container data types; variables, expressions, and statements; repetitive programming; algorithm; functions; working with files; exception handling and debugging; scientific programming.
