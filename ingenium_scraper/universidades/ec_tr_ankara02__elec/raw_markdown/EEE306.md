### Objectives of the Course

The aim of this course is to explain the instruction set architectures of microprocessors (assembly commands, addressing modes, command formats, run times etc.), internal structure of microprocessor, memory hierarchy and programming input/output ports.

### Course Content

Microprocessor based systems. An introduction to the ARM microprocessor family. Software Architecture: addressing modes. Data transfer instructions. Arithmetic, logical, bit manipulation, program transfer, and processor control instructions. Software and hardware interrupts. An introduction to the programming. Programming applications. Hardware architecture: hardware details of the ARM. Memory system design. I/O system design.
