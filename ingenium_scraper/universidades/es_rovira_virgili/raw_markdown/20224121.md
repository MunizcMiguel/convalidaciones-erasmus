# Fundamentos de tecnología electrónica y automática (20224121)

- Titulación: Grado en Ingeniería Mecánica · Universitat Rovira i Virgili
- Curso/periodo: Curso 3 / 2Q
- Créditos: 6.0 ECTS · Carácter: obligatoria

## Descripción general

DESCRIPCIÓ GENERAL DE L'ASSIGNATURA:

ESTUDIAR ELS DIFERENTS ELEMENTS QUE INTEGREN L'ELECTRÒNICA ANALÒGICA I DIGITAL. APLICACIÓ D'AQUESTS ELEMENTS A SISTEMES DIGITALS I DE CONTROL.

## Resultados de aprendizaje

| Tipo A | Código | Resultados de aprendizaje |
|---|---|---|
|  | A1.1 | Conoce los fundamentos de la electrónica. Conoce los fundamentos de automatismos y métodos de control. |
|  | A4.5 | Conoce los fundamentos de electrónica analógica y digital. Comprende las características de los procesadores digitales, el funcionamiento y sus aplicaciones. |
|  | A4.6 | Conoce las características y aplicaciones de los sensores y elementos de control. |
| Tipo B | Código | Resultados de aprendizaje |
| Tipo C | Código | Resultados de aprendizaje |

## Contenidos

| tema | Subtema |
|---|---|
| 1.- SEMICONDUCTORES. | Propiedades eléctricas del Ge y del Si. Termistores. VDR y LDR. Diodos de unión. |
| 2.- CIRCUITOS DE DIODOS. | Circuitos rectificadores. Medidores con rectificación. Multiplicadores de tensión. Fuentes de alimentación. |
| 3.- TRANSISTORES BJT ,JFET Y MOSFET. | Características. Modelos. Amplificadores básicos. Interruptores. Amplificadores de potencia. |
| 4.- AMPLIFICADORES OPERACIONALES. | Amplificadores diferenciales. Amplificadores de instrumentación. Circuitos básicos. |
| 5.- NOCIONES BÁSICAS DE ELECTRÓNICA DIGITAL | Circuitos combinacionales. Circuitos secuenciales. Procesadores. |
| 6.- SISTEMAS DE CONTROL REALIMENTADOS. | Realimentación negativa. Realimentación positiva. Osciladores. Controladores P. Controladores PD. Controladores PID. |
| 7.- INSTRUMENTACIÓN Y CONTROL DIGITAL Y ANALÓGICO. | Sensores. Instrumentos de medida. Circuitos de control. |
| 8.- SISTEMAS DE COMUNICACIÓN EN LA INDUSTRIA. | Telemedida. Telemando y telecontrol. Telecomunicaciones. |
