## Contents

Algorithms, programs and programming languages. Introduction to programming using the C language. Basics of the C language syntax. Control flow instructions. Data types; functions. Pointers; arrays; struct; dynamic memory allocation. String manipulation; the C I/O system. Preprocessor directives; debugging. Unix system calls: I/O; file system management, process management. Basic data structures: list, queue, stack, tree. Sorting and search algorithms.

## Learning objectives

This course is designed for first-year Computer Engineering students who have no prior programming experience but are familiar with using a computer. The primary objective is to introduce students to a procedural programming language and the implementation of solutions for simple problems. Particular emphasis will be placed on the process of taking a given problem, identifying the input and output data, developing a solution algorithm, and implementing it in the C language. The study of the C language will be deepened through an examination of key programming algorithms—such as searching, insertion, deletion, and sorting—applied to simple data structures, as well as algorithms for character string manipulation. This in-depth study will continue with topics specific to C programming, such as the use of pointers and functions. File handling and dynamic memory management will round out the course topics, alongside the presentation of standard algorithms for managing simple lists and dynamic arrays. Knowledge and understanding: By the end of the course, students will be able to understand the fundamental principles and concepts of procedural programming, know the syntax and features of the C language, and use basic functions from the ANSI C library. Applying knowledge and understanding: Students will be able to develop simple programs using the procedural programming paradigm in C. Furthermore, students will be able to read and comment on C code. Finally, students will be able to identify and resolve errors occurring at both compile-time and runtime (debugging). Making judgements: The student will be able to evaluate simple C programs and solutions, identifying the most suitable approach for solving a specific computational problem. Communication skills: The student will be able to explain the solutions implemented in their programs using appropriate technical terminology. Learning skills: The student will develop the ability to independently consult and explore the official documentation for the C language and libraries.

## Assessment methods

The learning assessment consists of a practical test in which the student must demonstrate the ability to develop a C program using a PC and an advanced program editor. The practical test consists of a maximum of three exercises proposed to the student, each characterized by an increasing level of difficulty. In particular, in this test particular attention is paid to evaluating the student’s ability to propose simple and canonical solutions to the problem posed. The student passes the practical test if he solves at least one of the proposed exercises. The student who passes the practical test is given a mark out of thirty, which the student can accept or not. Only if the student passes the written test with a grade higher than 26/30 can he/she also request to take the oral test. The oral test is therefore optional and, if taken, can also lead to the redetermination of the grade attributed to the practical test, depending on the preparation demonstrated by the student. In the optional oral test, the program developed in the practical test and the main topics presented during the course are discussed. In this test, the focus is mainly on ascertaining the level of knowledge of the C language.
