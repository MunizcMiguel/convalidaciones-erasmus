## Learning objectives

The course introduces the fundamental principles, methods, and tools of Software Engineering, providing students with the knowledge and skills required to analyze, design, develop, and verify software systems of medium complexity following an engineering approach. Particular emphasis is placed on modern object-oriented analysis and design techniques, iterative, incremental, and agile software development processes, software quality, software lifecycle management, and the use of collaborative software development tools. Upon successful completion of the course, students will be able to: understand the main phases of the software development process; model software requirements, structure, and behavior using UML; design object-oriented software architectures; apply established software design principles and design patterns; employ agile methodologies for software development; plan and perform software verification and validation activities; develop software collaboratively using version control and team collaboration tools; understand the principles underlying modern cloud platforms and DevOps practices. Dublin Descriptors Knowledge and Understanding Upon successful completion of the course, students will have acquired knowledge of the fundamental principles of Software Engineering, the main software development process models, object-oriented analysis and design methodologies, software verification and validation techniques, software quality principles, and the technologies and practices underpinning contemporary software development. Applying Knowledge and Understanding Students will be able to analyze software requirements, model software systems using UML, design object-oriented software architectures and components, apply established design principles and design patterns, employ agile software development methodologies, carry out software testing activities, and use software configuration management and collaborative development tools within a software project. Making Judgements Students will be able to critically evaluate alternative software design and architectural solutions, selecting appropriate methods, tools, and techniques according to system requirements, project constraints, and quality objectives. They will also be able to assess software quality aspects and critically appreciate the opportunities and limitations of modern software engineering technologies, including Artificial Intelligence-based software development tools. Communication Skills Students will be able to effectively document software analysis, design, implementation, and testing activities using appropriate models, diagrams, and technical documentation. They will also be able to communicate and justify design decisions, present project outcomes, and collaborate effectively within a software development team using appropriate technical terminology. Learning Skills Students will develop the ability to independently deepen their knowledge of emerging software engineering methodologies, technologies, and tools, enabling them to adapt to the continuous evolution of software development practices and to pursue further studies in the field.

## Prerequisites

Students are expected to have a solid knowledge of procedural and object-oriented programming and to be familiar with relational database systems. They should be able to design and implement software applications using appropriate algorithms, data structures, and object-oriented programming techniques, as well as interact with databases and network services. Basic knowledge of operating systems and integrated development environments (IDEs) is also beneficial. Required exam: Programmazione II

## Teaching methods

The course includes: - lectures (70%) devoted to the presentation of the theoretical foundations and methodologies of Software Engineering; - guided practical exercises (30%) on software modeling, design, and testing techniques; laboratory activities aimed at the development of a software project; - team-based projects simulating a professional collaborative software development environment. Throughout the course, students will use professional tools for version control, collaborative software development, and the automation of software build and testing activities. Where appropriate, Artificial Intelligence tools supporting software design and development activities will also be introduced, discussing both their potential benefits and limitations.

## Assessment methods

Student assessment consists of two components: - A group project (30%), including requirements analysis, software design, implementation, testing, and documentation of a software system, followed by a final presentation and discussion. - An individual examination (70%) aimed at assessing students&#39; understanding of the theoretical foundations, methodologies, and techniques presented during the course, as well as their ability to apply them to Software Engineering problems. Assessment will consider not only the technical correctness of the proposed solutions but also the quality of the software design, the documentation produced, teamwork skills, and the clarity of the presentation.
