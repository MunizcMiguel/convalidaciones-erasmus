## Program content ensuring the achievement of the learning outcomes prescribed to the module

1. Introduction to Python: Why Python?, environmental setup, run scripts, GitHub overview, use of documentation, basic syntax, variable types, basic operators, objects and data structures, strings, lists, tuples, dictionary. 2. Python methods and functions: Matplotlib library introduction – figures and axes creation, iterative figures, colormaps. File input/output, comparison operators, statements, conditionals and loops, linear algebra operations, statistics and random numbers, interpolation and fit. 3. Procedural programming in Python: Math and logic computations: selection, sorting, stack, queue etc. 4. Fundamentals of object-oriented programming in Python: OOP paradigms, attributes and class keyword, class object attributes and methods, function overloading, inheritance and polymorphism.5. Digital signal processing and visualisation in Python part 1 – introduction: Introduction to NumPy/SciPy library, signals importing and pre-processing, harmonics and stochastic signals, signal processing tools, data visualisation. 6. Digital signal processing and visualisation in Python part 2 – selected applications: Fast Fourier transform (FFT) for spectral analysis, discrete cosine transform (DCT) for data compression, noise reduction and signal filtering. 7. Electrical circuits analysis in Python part 1 - introduction: Introduction to Pyspice library, electrical and electronics elements representation, creating electrical diagrams. 8. Electrical circuits analysis in Python part 2 – selected applications: Modelling and analysis of electrical diagrams. 9. Electrical power system analysis and modelling in Python part 1 - introduction: Introduction to Pypower/Pandapower library, power flow analysis, interfacing with OpenDSS. 10. Power system analysis and modelling in Python part 2 – selected applications: Analysis of a power systems, influence of non-linear and variable loads, influence of distributed generation, reactive power compensation. 11. Power system analysis and modelling in Python part 3 – project: Solution of typical issues in modern power systems, influence of distributed generation, power factor improvement etc.12. Machine learning and deep learning in Python for electrical systems part 1 - Applications of Python artificial intelligence libraries. 13. Machine learning and deep learning in Python for electrical systems part 2 - data forecasting: Analysis of the operation of renewable energy sources using artificial intelligence methods. 14. Machine learning and deep learning in Python for electrical systems part 3 - system diagnosis: Analysis of the operation of a distributed power system using artificial intelligence methods.

### Additional info

Python is an interpreted, high-level and general-purpose programming language, being considered as one of the most popular programming language in the world, having a constantly growing group of users. Its syntax is simple and easy to learn which emphasizes readability. Python can be used for everything from web development to software development and scientific applications, therefore it is among the most in-demand skills by employers. Python is free and offers wide selection of open-source libraries and packages that are used in both scientific and technical applications. The course covers the introduction to the Python programming language and its applications in electrical engineering through: digital signal processing and visualisation, electrical circuits and power systems analysis and machine and deep learning (so popular nowadays) focused on the power system diagnostics. PyCharm (teaching licence) will be used as an integrated development environment.
