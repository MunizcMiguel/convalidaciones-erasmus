## Goals

- **C1**: Students will learn how to program and configure built-in Texas Instruments C2000 series floating-point microcontroller peripherals (TMS320F28379D - dual-core version) using Matlab / SIMULINK environment and the option of creating code in C language. Students learn the main rules of programming in the dedicated programming software Code Composer Studio (CCS) and the method of implementing the code in Matlab/SIMULINK with an extension to the C2000 chip. Students will learn how to prepare and correctly configure a project and learn debugging methods.
- **C2**: Students will gain practical knowledge and useful skills in the use of interrupt systems available in the TMS320F28379D microcontroller and the proper configuration of built-in peripherals based on the Texas Instruments evaluation kit extended with external signal interface systems, i.e .: I) GPIO digital inputs / outputs, II) counters, III) ePWM generators, IV) eQEP modules dedicated to the encoder, V) eCAP modules allowing for measuring the duration of external events, VI) analog / digital converters (ADC) and VII) digital / analog converters (DAC).
- **C3**: Students will gain practical knowledge and skills in the operation of drive systems and power electronic systems dedicated to electric vehicles and the infrastructure necessary for their charging in the Matlab/SIMULINK environment and transfer of the developed measurement, control or protection structure to a floating-point microcontroller using the option of automatic code generation in C.

## Program content ensuring the achievement of the learning outcomes prescribed to the module

The program of the subject implements the learning outcomes in the field of knowledge, skills and competencies in the area of ​​Electronics, Electrical Engineering and Automation with Robotics, in particular: the competence to use and practical use of the professional software. Graduates can use the acquired competences when starting work in various sectors of the economy wherever there is a need to use a microcontroller for: I) control and control of drive systems with electric motors, II) control and control of power electronic converters, III) measurement of electrical quantities.
