# Datacommunication: Lab

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

De student kan zelfstandig de documentatie (schema's, datasheets, programming manuals, ...) doorzoeken en begrijpen.
De student kan zelfstandig metingen uitvoeren en analyseren.
De student kan vanuit de beschikbare documentatie een protocol in software implementeren en debuggen.
De student is in staat om fouten te zoeken in een communicatie protocol (soft- en hardware fouten).

## Begintermen (vereisten)

Dit vak bouwt verder op het vak Embedded Systems.

## Onderwijsleeractiviteiten

3 studiepunten
Nederlands
Practicum
Tweede semester
POC PBA ELEKTRONICA-ICT STKA TMMA

## Inhoud

De volgende communicatie protocollen in software implementeren:
UART
I²C
SPI
De volgende communicatie protocollen in software implementeren met hardware ondersteuning:
Modbus via RS485
I2S
Volgende datastromen moeten gecapteerd worden en geanalyseerd worden met Wireshark
USB
TCP/IP

## Toelichting onderwijstaal

De onderwijstaal is Nederlands maar datasheets, software en documentatie zijn in het Engels.

## Studiemateriaal

Voor de opdrachten, datasheets, schema's, manuals, ... zie digitale leeromgeving

## Beoordelingsschaal

TOTAAL
1-20
Puntenschaal
100 % praktijk examen, gesloten boek.
Dit is een opdracht in de vorm:
Zorg er voor dat 2 entiteiten via een communicatie link juist met elkaar communiceren.
Dit kan (afhankelijk van de opdracht) door code te schrijven en/of door een bestaand systeem te debuggen.
Dit gebeurd op een PC van het labo en de code draait op 1 of meerdere microcontrollers.
Ook het kunnen werken met meetappartuur (logic analyser, Osciloscoop, ...) is een belangrijk deel van de evaluatie.
