# OS Advanced

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

(1)
De student zet DNS op in een Windows Server omgeving, en configueert deze op een redundante wijze, zodat er vanuit een computer in het netwerk DNS opzoekingen kunnen gedaan worden van zowel interne als externe namen, gebruik makend van het recursieve DNS lookup concept.
(2)
De student zet een Active Directory omgeving op, waarbij meerdere Domain Controllers op een redundante manier het beheer van deze omgeving mogelijk maken.
(3)
De student kan gebruik maken van Group Policies om allerhande beveiligingen/of automatisering te realiseren
(4)
De student kan een email server integreren in de Active Directory omgeving, zodat email kan verstuurd en ontvangen worden
(5)
De student zet Remote Access op, gebruik maken van een zelf te configureren VPN.
