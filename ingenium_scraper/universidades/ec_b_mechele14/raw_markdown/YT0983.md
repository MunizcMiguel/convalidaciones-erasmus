# Python for A.I.

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

- De student kan de behandelde topics uit de cursus benoemen
- De student kan de output van gegeven Python code voorspellen
- De student kan een werkende oplossing ontwerpen en programmeren om gegeven A.I. probleemstellingen op te lossen m.b.v. Python en bijhorende libraries zoals NumPy, SciPy, Matplotlib, Pandas, OpenCV, Scikit-learn, TensorFlow, etc. zoals gezien tijdens de oefeningen
- De student kan de code van deze AI oplossing uitleggen en de gemaakte keuzes motiveren.

## Begintermen (vereisten)

Het is aanbevolen Math for A.I. en Python gevolgd te hebben.

De evaluatie bestaat uit 2 delen:

De AI-specifieke concepten worden geëvalueerd via het opleidingsonderdeel AI Applications, voor studenten die dit opleidingsonderdeel ook opnemen in hun individueel studieprogramma.
