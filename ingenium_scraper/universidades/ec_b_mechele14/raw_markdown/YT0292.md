# Web Engineering

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

Leerdoelen:
(1) De student analyseert bestaande HTML en CSS code. Hij/zij vindt syntax fouten en schetst het resultaat van deze code zonder hulp van een browser of ander software programma.
(2) De student voorspelt het resultaat van bestaande JavaScript, jQuery en/of op XML gebaseerde code zonder hulp van een browser of ander software programma.
(3) De student gebruikt HTML en CSS om een website van een professioneel ogende lay-out te voorzien. Hij/zij ontwikkelt een website op een kwaliteitsvolle manier en maakt daarvoor gebruik van een correcte pagina structuur en robuuste CSS technieken.
(4) De student maakt een website interactief met behulp van JavaScript en/of jQuery.
(5) De student maakt gebruik van XML bestanden en op XML gebaseerde technieken om gegevens selectief weer te geven in een website.
(6) De student test de website tijdens het ontwikkelproces met het oog op het opleveren van een succesvol werkende software.
