# Embedded Operating Systems

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

De student kan zelfstandig de documentatie (schema's, datasheets, programming manuals, ...) doorzoeken en begrijpen.
De student moet zelf zijn ontwikkelomgeving kunnen opzetten.
De student is in staat om softwarefouten te zoeken ook in software die hij niet zelf gemaakt heeft.
De student begrijpt hoe linux drivers werken en kan hierin zelfstandig design beslissingen nemen en deze implementeren.
De student kan zijn proces en implementatie degelijk documenteren en kan zijn design keuzes mondeling verdedigen.

## Begintermen (vereisten)

Dit vak bouwt verder op OS Fundamentals, C Programming Fundamentals en Embedded Systems
