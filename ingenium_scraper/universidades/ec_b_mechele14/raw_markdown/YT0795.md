# Virtualisation Fundamentals

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

(1)
De student kan de basisconcepten van virtualisatie toepassen in Linux namespaces en cgroups en via KVM en Qemu werkende basis virtuele machines opbouwen.
(2)
De student beheerst de concepten van Qemu om code van CPU’s met andere ISA uit te voeren op een x86 CPU (systeem emulatie)
(3)
De student kan met Docker een omgeving opzetten en gebruiken om containers met persistente datavolumes op te zetten

## Begintermen (vereisten)

Een basiskennis van Linux en Windows besturingssystemen is een vereiste.
