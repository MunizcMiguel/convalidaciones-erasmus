# App Development

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

Leerdoelen
(1) De student kan de grote principes van Android beschrijven
(2) De student kan de verschillende principes toepassen in een opdracht
(3) De student analyseert het probleem en vertaalt dit naar een programma structuur en bijhorende algoritmes
(4) De student zet de structuur om in een programma met behulp van Java/Kotlin code specifiek voor Android
(5) De student zet de algoritmes om in het programma met behulp van Java/Kotlin code
(6) De student verifieert de werking van het programma t.o.v. de vereisten van de opdracht

## Inhoud

Introductie in Android app development.
Tijdens de theorie worden verschillende topics aangehaald die leiden tot het schrijven van een performante Android applicatie.
Volgende topics komen aan bod:
- Introduction to Android
- User Interface
- Navigation
- Lifecycle
- Application architecture
- Persistence
- RecyclerView
Afhankelijk van de tijd kan het zijn dat sommige topics niet gezien worden of andere bijgevoegd worden.
