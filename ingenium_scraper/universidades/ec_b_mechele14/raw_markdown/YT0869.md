# Hacking Expert Class

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

In een 6 tal sessies verdiepen de studenten hun kennis en leren over meer complexe security issues en verdedigingsmechanismen:
Via andere passieve en actieve bronnen waardevolle informatie verzamelen over potentiele target
Complexe kwetsbaarheden identificeren, exploiteren, rapporteren en mitigeren
Omgaan met security incidenten en deze onderzoeken
Welke geavanceerde beveiligingsissues kunnen voorkomen op netwerk-, infrastructuur- of applicatieniveau
Hoe hackers zich kunnen bewegen doorheen een netwerk
Hoe antivirus werkt en welke technieken deze kunnen omzeilen

## Begintermen (vereisten)

De student heeft het opleidingsonderdeel Information Security gevolgd.
De studenten moeten op voorhand VMWare Workstation en een Kali Linux Virtual Machine op hun laptop geinstalleerd hebben.
Kali Linux Virtual Machine te downloaden op: https://www.kali.org/downloads/

## Inhoud

Leerresultaten:
De student wordt tijdens deze lessen ondergedompeld in de verschillende facetten van het ethisch hacken. Tijdens deze lessen krijgen de studenten niet alles op een bordje aangereikt en wordt er van de studenten inzet en zelfstudie verwacht.
De student leert:
Hoe een aanvaller informatie verzamelt van een mogelijk doelwit
Hoe een aanvaller een informatiesysteem kan binnendringen
Raamwerken die de meest kritieke kwetsbaarheden beschrijven, kennen
Een (web)kwetsbaarheidsanalyse uitvoeren
Exploits uitvoeren
De student :
Kan kwetsbaarheden koppelen aan exploits
Heeft kennis van tools om aanvallen uit te voeren en kan deze gebruiken in een afgeschermde omgeving
Kent de kanalen waar kwetsbaarheden worden gepubliceert
Is in staat om op basis van de kwetsbaarheden de nodige maatregelen te nemen in een informatiesysteem
Krijgt de beginselen aangeleerd van reverse engineering
Inhoud:
Session 1: Information gathering and reconnaissance
Advanced passive information gathering
Advanced active information gathering
SMB
SMTP
SNMP
Exercises
Session 2: Network security, Infrastructure security and patch management

Advanced post-exploitation

Exercises

Defense in depth
Incident response

Exercises

Integrated Capture The Flag with technical challenges about all previous sessions
