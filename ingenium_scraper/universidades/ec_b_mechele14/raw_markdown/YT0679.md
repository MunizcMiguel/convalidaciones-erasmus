# Industrial Communication and Networking

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

Je kan van een PLC, de master op een industrieel netwerk,:
- de opbouw schetsen en de belangrijkste punten opsommen waarin deze zich praktisch onderscheidt van een microprocessor(-controller)bord
- zijn specifieke werking beschrijven
Je kan de meest voorkomende veldbussen beschrijven (waar toegepast, dragende fabrikanten, specifiek gebruik, …).
Je kan de specifieke begrippen, eigenschappen en terminologie beschrijven die gebruikt worden bij industriële netwerken.
Je kan van de aan bod gekomen netwerken de volgende zaken beschrijven/weergeven/tekenen :
* netwerkinterface (connectoren, kabels, signalen, specifiek nodige componenten)
* opbouw netwerk (mogelijke netwerktopolgieën)
* werking van het communicatieprotocol
* limitaties van het netwerk (lengte, snelheid, aantal componenten)
* compatibiliteit met Ethernet TCP/IP
Je kan een PLC-programma ontwerpen met de belangrijkste basisinstructies.
Je kan een profibus- en profinetnetwerk configureren in STEP7.
Je kan een profibus- en profinetnetwerk in dienst nemen.
Je kan een profibus- en profinetnetwerken diagnostiseren, zowel via de HW-configuratie als via een zelf geschreven programma.

## Inhoud

- Configuratie en programmeermodel van een S7-300-PLC (Siemens).
- Een eenvoudig programma (met de belangrijkste basisinstructies) maken.
- Opzetten van een Profibuisnetwerk met Siemens-PLC als master.
- Opzetten van een Profinetnetwerk met een Siemens-PLC als I/O-controller.
- Diagnose toepassen op een (falend) netwerk, via HW-configuratie en via zelf ontworpen programma.
