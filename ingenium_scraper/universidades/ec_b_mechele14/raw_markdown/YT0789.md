# Database fundamentals

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

1. Je kent de basisterminologie van databanken.
2. Je bent in staat een ERD-structuur te interpreteren en zelf te ontwerpen op basis van functionele eisen. Je kan dit diagram omzetten naar een concrete database. Je begrijpt hoe verschillende tabellen aan elkaar gelinkt zijn en je kan ze ook zelf correct linken via foreign keys en tussentabellen.
3. Op basis van een business vraag schrijf je SQL-statements waarmee alle gegevens worden opgehaald en getoond die relevant zijn om een antwoord te formuleren.
4. Je schrijft SQL statements voor de manipulatie van de gegevens : insert, update, delete.
5. Je kent het verschil tussen SQL en NoSQL databases en schrijft basis NoSQL-statements.
6. Je leert werken met DML (data manipulation language) - DDL (data definition language) - DCL (data control language)
7. Je bestudeert de optimalisering van SQL queries.
8. Je behaalt een certificaat voor een cloudserver.

## Inhoud

Data Manipulation Language: basis en gevorderd omtrent het opvragen en bewerken van gegevens in een databank:
select met o.a. group by, having, subquery, innerjoin, left- en right outerjoin, built-in functies, set-operatoren
insert, update, delete
Data Definition Language: tabellen, views, referentiële integriteit
ERD-structuur opstellen en omzetten naar relationele tabellen / Normaliseren
NoSQL : Introductie MongoDB, aggregatie functies
User roles
