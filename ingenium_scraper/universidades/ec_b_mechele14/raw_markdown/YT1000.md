# Software engineering

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

1) De student kan op basis van de analyse van bedrijfsprocessen een lastenboek opstellen
2) De student kan op basis van het lastenboek een functionele analyse opstellen
3) op basis van de functionele analyse kan de student een technische analyse maken van de te ontwikkelen software
4) Aan de hand van de voorgaande analyses kan de student een set tests opstellen voor de te ontwikkelen software
