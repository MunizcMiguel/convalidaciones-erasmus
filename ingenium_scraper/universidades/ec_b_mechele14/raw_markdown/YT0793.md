# Software Engineering

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

(1)
De student kan een lastenboek samenstellen op basis van de analyse van bedrijfsprocessen van een bedrijf naar keuze
(2)
Op basis van het opgestelde lastenboek kan de student een functionele analyse voor de te ontwikkelen software
(3)
Op basis van de functionele analyse kan de student een technische analyse maken voor de te ontwikkelen software
(4)
Aan de hand van de technische analyse kan de student een set testen voor de te ontwikkelen software opstellen
