# OS Fundamentals

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

(1)
De student kan een besturingssysteem (Linux en Windows) installeren op een computer
(2)
De student beheerst de concepten van de gebruikerinsterface, zowel een grafische als de command-line, om een aantal basis opdrachten te kunnen uitvoeren
(3)
De student is in staat om minimum 2 computers met mekaar in een netwerk te verbinden op een zodanige wijze dat er data kan gedeeld worden tussen die machines.
(4)
De student is in staat om defecten in de configuratie van een besturingssysteem te detecteren en te corrigeren
(5)
De student kan een besturingssysteem configureren om de veiligheid van gegevens te garanderen voor verschillende gebruikers van het systeem.
(6)
De student is in staat om software te installeren en te configureren op Linux en Windows besturingssystemen.
(7)
De student beheerst verschillende technieken van opslag, zowel lokaal als via een netwerk, en kan deze configureren en combineren.

## Inhoud

In dit opleidingsonderdeel wordt de basis gelegd voor het gebruik van besturingssystemen zoals Linux en Windows, en hoe ze samenwerken binnen een klein netwerk.

Introductie tot de Command Line Interface van Linux: basis commando's

Installeren van software/applicaties

Stappen bij het opstarten van een systeem
Kernel van een besturingssysteem
