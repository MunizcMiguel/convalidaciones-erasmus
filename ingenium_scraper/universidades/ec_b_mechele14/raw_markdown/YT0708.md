# PHP & MySQL

Studiepunten (ECTS): 6

## Doelstellingen (leerdoelen)

Leerdoelen
:
(1) De student voorspelt het resultaat van bestaande PHP en JS code zonder hulp van een server of ander software programma.
(2) De student is in staat een ERD-diagramma te begrijpen en zelf te ontwerpen op basis van functionele eisen. Hij/zij kan dit diagramma omzetten naar een concrete databank. Hij/zij begrijpt hoe verschillende tabellen aan elkaar gelinkt zijn en kan ze ook zelf correct linken via foreign keys en tussentabellen.
(3) De student schrijft SQL queries waarmee alle gevraagde data uit een databank wordt opgehaald en getoond en voorspelt het resultaat van een SQL query voor een gegeven databank.
(4) De student ontwikkelt een werkende web applicatie met bijhorende databank.
(5) De student gaat ethisch om met bronbestanden, broncode en libraries die online of in handboeken teruggevonden worden.
(6) De student ontwikkelt een robuust datamodel voor zijn/haar web applicatie, vertaalt dit in een ERD diagram en zet dat om in een databank.
(7) De student gebruikt de correcte technologieën voor de verschillende onderdelen van de applicatie.
(8) De student bouwt beveiliging in om misbruik van de applicatie te vermijden.
(9) De student test de applicatie tijdens het ontwikkelproces met het oog op het opleveren van een succesvol werkend geheel dat voldoet aan de vooropgestelde eisen.
(10) De student maakt een realistische en effectieve planning van de eigen activiteiten en processen. Hij/zij levert het project op tegen de vooropgestelde deadline.

## Inhoud

Een dynamische website biedt veel meer mogelijkheden dan een 'gewone' statische website. De technologieën die hierachter schuilgaan worden in deze lessen uit de doeken gedaan.
Naast een webserver wordt er gebruik gemaakt van een database server (MySQL) om gegevens te bewaren en op te vragen.
Serverscripts (PHP) zorgen voor een volledig dynamische website of web applicatie. Aan de hand van deze scripts, kan men zoekacties verrichten, informatie op maat opvragen, zich inschrijven op services, enz.
Uiteraard moet bij dit type van websites aandacht besteed worden aan veiligheid. Om de gebruikerservaring te optimaliseren worden grotere gegevenspakketten asynchroon ingeladen.
Tot slot wordt ook aandacht besteed aan het correct opbouwen van een databank voor de web applicatie.
