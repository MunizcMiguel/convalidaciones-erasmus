# Scripting

Studiepunten (ECTS): 3

## Doelstellingen (leerdoelen)

Leerdoelen
(1) De student maakt kennis met windows powershell en bash scripting
(2) De student schrijft een eenvoudig script
(3) De student gaat op zoek naar de werking van componenten in script
(4) De student zet de opdracht om in een script
(5) De student verifieert de werking t.o.v. de vereisten

## Inhoud

Tijdens de theorie wordt kennis gemaakt met windows PowerShell en de GNU Bash terminal.
Voor beide terminals bekijken we ook de scripting mogelijkheden.
Op deze manier leren we hoe bepaalde processen kunnen geautomatiseerd worden voor zowel windows als linux systemen.
Ook wordt er gekeken naar hoe scripts kunnen getest en gedebugged worden.
