# Database Systems

- **Form of course completion**: Examination
- **Accredited / Credits**: Yes, 4 Cred.
- **Type of completion**: Combined
- **Time requirements**: Lecture 2 [HRS/WEEK] Tutorial 2 [HRS/WEEK]
- **Language of instruction**: English
- **Semester taught**: Summer semester
- **Optional course**: Yes
- **Prerequisite courses**: N/A

## Course objectives

The aim of the subject is to learn the basis of SQL language in practical use.
The subject is only for ERASMUS students.

## Requirements on student

To obtain the assessment and examination, the student must complete the requirements:
1) Pass all tests.
2) For tests, only the result of the first attempt is counted.
3) You will then be graded on the following scale:
100-90% - Grade "A"
89-80% - Grade "B"
79-70% - Grade "C"
69-60% - Grade "D"
59-50% - Grade "E"

## Content

Relational databases, database server, tables. Tools for work with Oracle database.
SQL language, DDL, DML. Datatypes.
Statement Select - basic syntax, projection, restriction.
Statements Insert, Update, Delete.
NULL values, operators, conditions.
Inner and outer joins of tables.
Group aggregations, aliases, sorting.
Subqueries, set operators.
SQL functions.
Database design, relations, E-R diagrams.
Normal Forms, normalisations.
Table creation, constrains, primary keys, foreign keys.
Views, sequences.
Indexes.
Data Dictionary.
All study materials are part of the e-learning course. The subject is taught only in the form of e-learning.

## Literature

Basic:
Oracle Academy. Lectures and Presentations.

## Prerequisites - other information about course preconditions

The course is intended for students who have no experience with relational databases and SQL language.

## Competences acquired

Master of the elementary work with SQL language in Oracle database system.
