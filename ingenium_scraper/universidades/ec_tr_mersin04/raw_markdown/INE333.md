# INE333 — INTRODUCTION TO R PROGRAMMING

ECTS: 4 · Year 3 · Semester 5 · optativa · content year id 47

## Prerequisites

None

## Objectives of the course

The aim of this course is to teach industrial engineering students the R programming language for data analysis, optimization and modeling, to provide basic programming skills and to provide competence in using R in industrial engineering applications such as statistical analysis, visualization and simulation.

## Course content

This course aims to teach industrial engineering students the basic and advanced use of the R programming language. The content starts with the installation and basic syntax of R and covers basic topics such as data structures, data reading and transformation operations. While students learn data visualization techniques using popular libraries such as ggplot2, they will also have the opportunity to apply advanced analysis methods such as basic statistical analysis, regression models and hypothesis testing. In addition, industrial engineering-specific topics such as optimization problems, Monte Carlo simulations and time series analysis will be covered. In addition to theoretical knowledge, the course aims to develop practical skills through project studies on real-world data. In the final weeks, students will make a comprehensive project presentation using the analysis and modeling techniques they have learned.

## Learning outcomes

1. Explain the basic syntax and data structures of the R programming language.
2. Implement data reading, cleaning and transformation operations using R.
3. Make effective data visualizations using ggplot2 and tidyverse libraries.
4. Perform basic statistical analysis and hypothesis testing with the R programming language.
5. Apply regression models and time series analysis using R.
6. Solve optimization and simulation problems specific to industrial engineering using R.
7. Prepare project presentations by analyzing real data sets.
