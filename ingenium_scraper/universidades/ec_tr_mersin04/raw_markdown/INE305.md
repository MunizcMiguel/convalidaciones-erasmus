# INE305 — OPERATIONS RESEARCH II

ECTS: 6 · Year 3 · Semester 5 · obligatoria · content year id 47

## Prerequisites

None

## Objectives of the course

The aim of this course is to develop students' competence in using mathematical modeling, problem solving and optimization techniques by providing basic knowledge and skills in advanced operations research topics such as integer linear programming, goal programming and transportation problems.

## Course content

Formulation and solution of integer linear programming, goal programming, transportation and transit problems, game theory, GAMS/LINGO applications, and solution techniques for mathematical optimization problems.

None

## Learning outcomes

1. Understand and model integer linear programming formulations.
2. Solve integer linear programming and goal programming problems with appropriate techniques.
3. Express transportation and transfer problems mathematically and apply solution methods.
4. Recognize game theory concepts and use this theory in decision-making processes.
5. Create mathematical models using software such as GAMS and LINGO and analyze their solutions.
