# INE204 — OPERATIONS RESEARCH I

ECTS: 7 · Year 2 · Semester 4 · obligatoria · content year id 47

## Prerequisites

None

## Objectives of the course

The aim of this course is to provide students with a solid foundation in the basic concepts and methods of operations research. The course focuses on linear programming models, solution techniques, duality, sensitivity analysis, and transportation and network models, helping students develop problem-solving skills and analytical thinking.

## Course content

Introduction to operations research, linear programming models and solution methods, duality and sensitivity analysis, transportation problems, network models, and software applications for optimization.

None

## Internship status

None

## Learning outcomes

1. Define fundamental concepts and historical development of operations research.
2. Formulate linear programming models for real-world problems.
3. Solve linear programming problems using graphical and algebraic methods (Simplex and Big-M methods).
4. Conduct sensitivity analysis and interpret duality in linear programming.
5. Model and solve transportation problems using the transportation simplex method.
6. Develop network models and use appropriate algorithms to solve them.
7. Utilize software tools to solve linear programming and network models.
