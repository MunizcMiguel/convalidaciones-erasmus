# INE407 — PROJECT MANAGEMENT

ECTS: 4 · Year 4 · Semester 7 · optativa · content year id 47

## Objectives of the course

Students will be able to define the project, plan the project, program the project resource management and analyze the project process.

## Course content

Since resources are very important elements for a project, this course covers the definition of the project, the project plan and the programming of project resource management, scheduling and analysis of the project process. The course covers the project manager, his team and their roles. Risk management in the project, project evaluation and control are examined. Finally, project closure is covered.

## Recommended or required reading

- Adedeji Badiru, (2012), Project Management Systems, Principles and Applications, CRC Press.
- Ilgın ACAR (editör), (2019), Proje Yönetimi, T.C. Anadolu Üniversitesi Yayınları

## Learning outcomes

1. Define what a project is.
2. Explain project planning step by step.
3. Prepare project scheduling with basic scheduling methods.
4. Perform basic analysis to determine necessary changes in the project plan.
5. Calculate the allocation of resources used in the project.
6. Explain all team members involved in the project.
7. Explain the analysis of risks in the project.
8. Calculate the level of progress of the project as planned.
9. List what is included in the correct termination of the project.
