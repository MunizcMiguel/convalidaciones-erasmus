# Presentation Skills

- Code: E113020
- ECTS: 2.0

## Synopsis

1. An overview of the basic tools of presentation using a PC and an introduction to
the psychology of students
2. Forms of presentation in relation to the environment where the presentation will
take place
3. Creating a presentation scenario and choosing appropriate tools to engage the audience
4. MS PowerPoint tools and their use in the preparation of technical presentations
5. Use specific tools for a given topic
6. Examples of using different types of animations to achieve the necessary effects
7. Ways to save presentations and convert to various formats, including video creation
