# Small robot design

- Code: E146003
- ECTS: 2.0

## Synopsis

This practical subject connects knowledge from mechanics, control, measurement, algorithms
and microcontrollers. The goal is to build a small autonomous robot. The student should
have some basic knowledge from sensors, electronics components and microprocessors
before choosing this subject.
web page: http://control.fs.cvut.cz/en/srd
Fundamentals of mechanical design for robots
Basics of 3D modeling (Autodesk Inventor)
Modeling for manufacturability for 3D printing
RC servos, functions and connections
Basics of Arduino programming
Robot assembly and testing of movements

## Requirements / prerequisites

The student should have some basic knowledge from sensors, electronics components
and microprocessors before choosing this subject.
