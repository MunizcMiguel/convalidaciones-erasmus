# Practical Software Tools

- Code: E372042
- ECTS: 3.0

## Synopsis

This course should match the students knowledge of informatics and information technologies
with the university standard.
MS Word and MS Excel in the range required to prepare a technical report or a scientific
article. MS Powerpoint and Matlab.
HTML code as an example of a markup language.
Lectures extending the range of the course in related areas.

## Syllabus of lectures

L1. Information systems and study support systems used at CTU in Prague, security
principles
T1. Text processors. Task: MS Word document. Advanced text formatting, tables, equations.
L2. A computer program as a model of a real problem
T2a. References. Where to find resources in a science research or in engineering.
T2b. MS Excel. Draw a graph from the given data.
L3. Data structures and operations on them
T3. MS Excel. Equations, functions including statistical and matrix functions. Conditional
formatting.
L4. Algorithmization of the problem and writing the appropriate algorithm
T4. Matlab and Simulink
L5. Programming languages overview (C, MatLab, Python,)
T6. Web (html and css, html source modification)
L6. Web programming tools.
T7. Final test and classification.
T - trainings, L - lectures. Participation on trainings required. Test in the range
of trainings.

## Syllabus of tutorials
