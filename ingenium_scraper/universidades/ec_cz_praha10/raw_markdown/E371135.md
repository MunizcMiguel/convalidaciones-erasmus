# Programmable Logic Controllers and Visualisation

- Code: E371135
- ECTS: 5.0

## Synopsis

PCA course suitable prior to this course
Application of the SCADA (Supervisory Control and Data Acquisition) system Reliance
in PLC control of the technological process models.

## Requirements / prerequisites

PCA course suitable prior to this course

## Syllabus of lectures

1. Basic characteristics of the SCADA systems
2. SCADA system Reliance
a)introduction
b)modules of the SCADA system Reliance
c)basic description of the design environment
(stations manager, pictures manager, floating graphs manager,...)
3.Supervisory and visualization application creation for the technological process
model controlled by a PLC(programmable logical controller)

## Syllabus of tutorials

1. Basic characteristics of the SCADA systems

a)introduction
b)modules of the SCADA system Reliance
c)basic description of the design environment
(stations manager, pictures manager, floating graphs manager,...)
3.Supervisory and visualization application creation for the technological process
model controlled by a PLC(programmable logical controller)

## Study objective (learning outcomes)

Creation of the visualizaton and supervisory application in the Reliance system for
various types the technological process models controlled by various PLC systems.
