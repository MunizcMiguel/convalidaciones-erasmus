## Course Learning Outcomes: Upon the successful completion of this course, students will be able to:

| No | Learning Outcomes |
|---|---|
| 1 | Explains the basic building blocks of PLC systems. Identifies basic components such as input/output modules, processor, and memory unit. |
| 2 | Understand the role of PLC in industrial automation. Evaluate why and how PLC is used in industry and its advantages. |
| 3 | Distinguish between different PLC models and programming languages. Have knowledge of languages ??such as Ladder Diagram (LD), Function Block Diagram (FBD), Structured Text (ST), etc. |
| 4 | Programs basic logic circuits in a PLC environment. Develops applications using basic commands such as AND, OR, NOT, timer, and counter. |
| 5 | It connects PLCs to industrial equipment such as sensors, relays, and motors. It interacts with peripheral elements connected to the PLC in real hardware or simulation environments. |
| 6 | Analyzes PLC programs, detects and corrects errors. Examines the logical flow of a created program and solves problems. |
