# Competências transversais: aquisição automatizada de dados laboratoriais

- Teaching language: Portuguese
- Edition: Instance: 2025/2026 - 2S (of 18-02-2026 to 05-06-2026)

## Objectives

To promote competences on automation and data acquisition.

## Learning outcomes and competences

Students should become able to: - Identify the relevant characteristics of a measurement device - Indentifythe relevant characteristics of a analog/digital conversion system - Properly connect mesurement devices toanalog/digital conversion systems - Develop a data acquisition program

## Program

Introduction 1. Measuement devices 2. Data acquistion systems 3. Data acquisitionprogramming Lab practice Introduction to programming with LabVIEW Creation of a data acquisition program Implementation of data reading and storage Creation of a serial RS-232 communication program Implementation ofserial communication

## Working method

Presencial

## Teaching methods and learning activities

Expositive and active methods will be used. Introductory modules will be given in classroom. Laboratory practice will be performed in a computer room.

## Evaluation Type

Distributed evaluation without final exam

## Assessment Components

Designation Weight (%) Laboratory work 60,00 Test 40,00 Total: 100,00

## Calculation formula of final grade

Final Grade = 0.6 x practical work + 0.4 x test

## Eligibility for exams

Faximum 25 % absence, according to FEUP's regulations.
