# Programming Networked Systems

- **Code**: ELEC-C7260

- **Credits**: 5 ECTS

- **Programme module path**: Major > Information Technology

## Learning outcomes

After the course student will be able to:

- Explain how core Internet protocols (DNS, HTTP, TCP, UDP) support networked applications

- Implement client-server systems using sockets, including concurrent servers

- Compare approaches to concurrency: processes, threads, asynchronous runtimes and their performance implications

- Apply basic security mechanisms such as TLS to protect communication

- Design and implement a networked application project

## Content

The course covers principles and practices for designing and implementating distributed networked applications. During the course students develop a networked system using the technologies covered.

Topics include:

- Operation of basic Internet protocols

- Socket programming at client and server

- Handling concurrency and asynchronous runtimes

- Using containers to deploy the network applications

- Security in network programming, for example TLS

## Prerequisites

Recommended prerequisites: ELEC-C7241 Tietokoneverkot, ELEC-C7420 Basic principles in Networking, or similar elementary computer networks course; Basic programming skills (e.g. using C or Python); Linux/Unix basic skills
