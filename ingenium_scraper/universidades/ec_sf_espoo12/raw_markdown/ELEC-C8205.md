# Automation Systems 1

- **Code**: ELEC-C8205

- **Credits**: 5 ECTS

- **Programme module path**: Major > Automation and Robotics

## Learning outcomes

The student is aware of the different automation solutions for different application areas, especially process automation and manufacturing. The student is familiar with the structure and main functions of automation systems and can apply the knowledge to the design and implementation of automation projects.

## Content

Automation systems: objectives, structure, functions and implementation alternatives. PLC programming. Automation design, project planning and quality control.

## Prerequisites

Recommended prerequisites: ELEC-C1110 Basic course in Automation and Systems Technology ELEC-A7100 Basic course in C-programming or equivalent knowledge
