# Mathematical Software

- **Code**: ELEC-A5140

- **Credits**: 2 ECTS

- **Programme module path**: General Studies

## Learning outcomes

Student can fluently read, process, save and present grafically data and can make simple programs and solve simple problems with mathematical software.

## Content

Data handling and presentation with Matlab, most important functions and programming with Matlab, also possibly some basic functions with other programs.

## Prerequisites

Recommended prerequisites: High school mathematics, basics in matrix calculations
