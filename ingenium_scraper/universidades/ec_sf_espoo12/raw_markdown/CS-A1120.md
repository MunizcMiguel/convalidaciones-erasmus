# Programming 2

- **Code**: CS-A1120

- **Credits**: 5 ECTS

- **Programme module path**: Major > Electronics and Electrophysics

## Learning outcomes

After successfully completing the course you have gained further experience in programming and problem-solving using computers.

You will be able to describe the structure of a programmable computer and how it may be built from the bottom up using logic circuits. You can explain how basic data types (bytes, integers, floating point numbers, ...) and structures (such as arrays and lists) are implemented and represented in computer memory. You have also gained experience in low-level programming using an assembly language.

You can define computational resources (time, space, ...) and connect these to the performance of basic functions in terms of bounds, and have familiarised yourself with basic searching and sorting algorithms.

You will have gained further experience with recursion as well as the functional programming paradigm, and are able to employ these techniques in your own programs. You can describe the role of types and collections in a high level language, and will have experienced debugging, testing, and explaining computer code.

## Content

Principles of binary representation of integers and floating point numbers. Bit-level operations. Gates as basic logic operators and how these can be combined to create circuits (e.g. for an adder). Basic computer architecture (von Neumann model) from gate level to high-level programming. Implementation of small programs in assembly language. The big-O definition, and concepts of computational resources. The algorithms binary search and selection sort. Collections (e.g sequences, arrays, and lists), traits, types, and mutability. Aspects of functional programming, e.g. pure functions, anonymous functions, closure and currying. Tail recursion and recursive data structures. Independent programming and problem-solving with computers.
