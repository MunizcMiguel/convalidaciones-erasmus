# Matematik I

## Ders Bilgileri

### Ön Koşul Dersleri

(boş)

### Dersin Seviyesi

Lisans

### Dersin Verilişi

Yüz yüze

### Dersin Amacı

Matematik ile ilgili temel kavramlar verilerek, tek değişkenli
fonksiyonlarda limit, süreklilik, türev kavramlarının ve
uygulamalarının verilmesi

### Dersin İçeriği

Kümeler (Küme işlemleri, açık küme, kapalı küme, yığılma noktası, vb.), Sayı Kümeleri (Doğal Sayılar, Tam Sayılar, Reel Sayılar ve Özellikleri), Supremum ve Infimum Kavramları, Fonksiyon Kavramı ve Özellikleri, Bazı Özel Fonksiyonlar, Fonksiyonlarda Limit, Süreklilik, Düzgün Süreklilik, Reel Sayı Dizileri, Reel Sayı Dizilerinde Sınırlılık ve Yakınsaklık, Bolzano-Weierstrass Teoremi, Türev Kavramı, Türev Almada Genel Kurallar, Türev Yöntemleri, Yüksek Mertebeden Türevler, Türevin Geometrik ve Fiziksel Anlamı, Türevle İlgili Teoremler, Belirsiz Şekiller, Diferansiyel Ve Eğri Çizimleri.

## Ders Öğrenme Kazanımları

| # | Öğrenme Kazanımı |
|---|---|
| 1 | Tek değişkenli fonksiyonlar, limit, süreklilik ve türev kavramlarını öğrenerek mühendislik problemlerine uygulayabilme. |
| 2 | Diferansiyel hesap yöntemlerini kullanarak fiziksel ve mühendislik sistemlerinin analizini yapabilme. |
| 3 | Fonksiyonların grafiklerini inceleyebilme, değişim oranlarını yorumlayabilme ve optimizasyon problemlerini çözebilme. |
| 4 | İntegral kavramını ve temel integral alma tekniklerini kullanarak alan, hacim ve mühendislik uygulamalarına yönelik hesaplamalar yapabilme. |
| 5 | Matematiksel düşünme, problem çözme ve analitik analiz becerilerini geliştirerek makine mühendisliği derslerine temel oluşturabilme. |

## Ders Planı (Haftalık Konular)

| Hafta | Konular/Uygulamalar | Yöntem |
|---|---|---|
| 1. Hafta | Kümeler. Sayı Kümeleri. Denklemler. Özdeşlikler. Eşitsizlikler. |  |
| 2. Hafta | Fonksiyon kavramı. Fonksiyonların özellikleri (1-1, örten. vs.) |  |
| 3. Hafta | Trigonometrik, ters trigonometrik ve hiperbolik fonksiyonlar. Parçalı fonksiyonlar, özel tanımlı fonksiyonlar (Mutlak değer, tam değer, işaret fonksiyonları) |  |
| 4. Hafta | Limit kavramı ve limit tanımı ile limit hesabı. Limit hesabı için kullanılan kuralların ispatı. Sandviç teoremi. Trigonometrik fonksiyonların limitleri. |  |
| 5. Hafta | Sağ ve sol taraflı limitler. Belirsiz haller (0/0,sonsuz/sonsuz, 0.sonsuz, sonsuz-sonsuz,1^sonsuz) |  |
| 6. Hafta | Fonksiyonlarda süreklilik kavramı. Süreksizlik çeşitleri. Sürekli fonksiyonların özellikleri ( Aradeğer teoremi, mutlak maksimum ve minimum, yerel maksimum ve minimum tanımları, …) |  |
| 7. Hafta | Türev kavramı ve türev tanımı ile türev hesabı. Türev tanımı ile türev alma kurallarının ispatı. Ters fonksiyonun türevi. |  |
| 8. Hafta | Yüksek mertebeden türev. Parametrik denklemleri verilen fonksiyonların türevleri. Kapalı fonksiyonların türevi |  |
| 9. Hafta | Arasınav |  |
| 10. Hafta | Teğet ve normal denklemi. Artan ve azalan fonksiyonlar. |  |
| 11. Hafta | Diferensiyel Kavramı ve yaklaşık hesap. Belirsiz Haller (L’Hopital Kuralı ile 8 belirsizlik halinin incelenmesi). |  |
| 12. Hafta | Fonksiyonların maksimum ve minimumu, asimptotlar |  |
| 13. Hafta | Eğri çizimleri. |  |
| 14. Hafta | Mühendislik problemleri. Diferansiyel ile yaklaşık hesap.Seri açılımları |  |

*Ara sınav ve final sınav tarihleri 14 haftalık ders işleyiş planında belirtilmemiştir. Ara sınav ve final sınav tarihleri Üniversitemiz Senatosu kararı ile akademik takvimde belirtilen tarihlerde yapılmaktadır.
