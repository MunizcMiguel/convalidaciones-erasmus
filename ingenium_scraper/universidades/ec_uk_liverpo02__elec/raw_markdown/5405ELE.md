# Instrumentation and Control Engineering (5405ELE)

- Level: FHEQ Level 5
- Credits: 20 UK credits (≈ 10 ECTS)
- Catalogue version: 2025.01
- Teaching period: January (12 Weeks); language of instruction: English

## Overview

This module develops your understanding of components and the principles of control systems, basic design and analysis techniques, and practice some control applications.

## Content / description

Temperature measurement: thermometers, thermistors and thermo-couples Force and weight measurement: strain gauges and bridge circuit Displacement measurement: potentiometers, LVDT (linear variable difference transformer) P&ID Diagrams Introduction: control system structure including sensors, controllers, actuators and plants. Matlab/Simulink Modelling & Simulation: introduce transfer function models for different plants, how to simulate a control system with Matlab/Simulink for system analysis and performance assessment. Block diagram analysis. Stability analysis: pole location method and Routh method Time response analysis: characteristics for first order and second order systems, response to step and ramp input. Controller design: design specification in time domain, functions of P, I and D control, empirical controller parameter setting method. State space representation Computer packages will be used to gain experience in applying and simulating techniques.

## Learning activities

- Tutorial: 11 hours
- Lecture: 22 hours
- Practical: 11 hours

## Learning outcomes

- MLO1: Analyse measurement devices for temperature, position and force.
- MLO2: Demonstrate an understanding of the basic concepts of dynamic system response and closed loop control.
- MLO3: Develop models for simple dynamic plant.
- MLO4: Design controllers and analyse system performance.
- MLO5: Simulate control systems with appropriate software and assess system
performance.
