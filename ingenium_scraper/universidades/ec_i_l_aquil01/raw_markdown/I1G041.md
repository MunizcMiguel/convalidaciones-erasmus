## Learning outcomes

With the course the student will be able to: - acquire knowledge of the basics of computer science and programming languages - know how to apply the knowledge acquired in the development of simple programs - understand programs of simple or intermediate size - have autonomy and the ability to continue learning on more complex computing systems and programming environments

## Learning objectives

This course contributes to the educational objective of the Degree Course by providing students with solid knowledge and operational skills on transversal engineering aspects, such as computer science. The course starts with a description of the computer system in general and then focuses on "high level" programming techniques with the aim of making students develop the ability to design programs. The reference language will be Python, a new-generation object-oriented language that facilitates learning for novice students by enabling them to immediately use the programming language to solve real problems of practical interest, such as graphical applications. The course also deals with the study of fundamental algorithms, such as the main search and sorting algorithms with the execution time calculation.

## Prerequisites

There are no mandatory prerequisites, but a so-called computer literacy is useful, such as being able to use a personal computer to manage files and access the internet to download and install new software. The basic notions of algebra and mathematical analysis are also useful as they are used during the course to design programs on simple mathematical problems.

## Contents

1. Introduction to computer systems. Processes and processors. Problems, algorithms and programs. Programming languages. Computer architecture. Von Neumann model.
2. Fixed-base positional number systems. Base conversions. Representation of negative numbers. Representation in floating point. ASCII code. Boolean algebra.
3. Design algorithms with flow charts. Concept of variable. Elementary operations. Pseudo-code. Control structure if-then-else. Cycles with pre-condition.
4. Python programming environments. Spyder. Console. Variable Explorer. Debugging. JupyterLab. Notebook. Kernel. Cell Types: Code, Markdown, Row.
5. Python programming language. Declaration of variables. Type classification. Numerical and conditional expressions. Assignment statement. Compound statement. Binary selection. Standard input / output functions. Cycle statements (WHILE, FOR).
6. Programming with compound types. Vectors and matrices. Lists. Strings.
7. Programming with functions. Declaration of functions. Local variables. Formal and actual parameters. Memory usage. Life cycle of variables. Visibility of variables. Masking of variables. Recursion.
8. Fundamental algorithms. Calculation of execution time. Best case, worst case, and average case. Computational complexity. Sequential search. Binary search. SelectionSort. InsertionSort. BubbleSort. Mergesort. Quicksort.
9. Text files. Tuples. Dictionaries. Sets.
10. Object-oriented programming. Definition of classes. Attributes and methods. Inheritance. Object-oriented design.
11. Vector graphics with Matplotlib library.
12. Image processing with PIL library.

## Teaching methods

The course consists of both frontal lessons and classroom exercises. To facilitate learning, the theoretical lessons are always accompanied by exercises to be performed at home and subsequently corrected in the classroom with the contribution of all the students. Python programs are performed by students directly on the computer.

## Assessment methods

During the course, programming exercises are carried out both in the classroom and at home with subsequent group correction. The final assessment test consists of two phases: - computer-based exam in which the student must carry out a few Python programs (20 points); - oral exam for a final evaluation of the entire course syllabus (10 points).

Final grades will reflect the following levels of preparation:

- sufficient: minimal knowledge of computer science concepts and just sufficient ability to program in Python;

- adequate: fair knowledge of the course contents and sufficient ability to program in Python;

- good: good knowledge and understanding of the course contents with good results in Python programming;

- in-depth: excellent knowledge and understanding of the course contents with notable results in Python programming.
