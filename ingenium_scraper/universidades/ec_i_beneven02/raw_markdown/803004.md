## Contents

The syllabus of the course (9 ECTS - 72 hours) covers the following topics: 1. Foundations of Computer Science and Architectures: information representation, numbering systems and encoding, binary arithmetic, Boolean algebra, basic concepts and models of computer architecture. 2. Algorithms and Programming: introduction to algorithms and programming languages. 3. Introduction to C Programming: structure of a C program, preprocessor directives and macros, variables, constants, primitive data types, and expressions. 4. Control Flow and I/O: formatted input/output, arithmetic and logical-relational operators, control flow structures (conditional and iterative statements). 5. Modularity: function definition and invocation, parameter passing (by value and by reference), variable scope. 6. Pointers and Linear Data Structures: one-dimensional and multi-dimensional arrays, pointers and pointer arithmetic, relationships between arrays and pointers. 7. Complex Data Structures: strings and string manipulation functions, structures (struct), unions (union), and enumerations (enum). 8. Memory Management: dynamic memory allocation. 9. Algorithms on Arrays: classic algorithmic schemes for searching (linear, binary) and sorting (bubble sort, selection sort, etc.). 10. Operating System Interaction and Files: the I/O system, file system management (text and binary files), introduction to process management.

## Learning objectives

The overall objective of the course is to provide students with the theoretical foundations of computer science, computer architecture, and the principles of structured programming as a tool for specifying algorithms, using the C language as a reference. Upon successful completion of the course the expected learning outcomes are: • D1. Knowledge and understanding: at the end of the course, the student will be able to understand the logical organization of a computer, the digital representation of information, the syntax and semantics of the C language, and the fundamental methodologies for structured algorithm design. • D2. Applying knowledge and understanding: the student will be able to apply C language constructs to implement, analyze, and debug software programs aimed at solving scientific and management computing problems. • D3. Making judgements: the student will be able to evaluate and interpret the efficiency and correctness of an algorithm, independently selecting the most appropriate data structures and programming strategies for a specific problem. • D4. Communication skills: the student will be able to communicate design choices clearly and with technical terminology, properly documenting source code and describing software logic. • D5. Learning skills: the student will develop the capacity to independently deepen further aspects of software development, approach new programming languages in the future, and effectively utilize user manuals and technical standards.

## Prerequisites

Basic logical-mathematical knowledge is required. There are no mandatory prerequisites for taking the final exam.

## Teaching methods

In line with the total hours of the course (72 hours), the educational activity is distributed as follows: - Lectures (70% - approx. 50 hours): dedicated to the explanation of theoretical foundations, computer architectures, and C programming syntax, using slides and blackboards. - Practical exercises and workshops (30% - approx. 22 hours): dedicated to guided development, real-time code execution, and solving practical programming problems on the computer. - E-learning Platform: supplementary learning materials, exercise assignments, and guidelines for self-study are available on the HANDY Unisannio university platform, accessible also to working and non-attending students. Course attendance is not mandatory, but active participation in classroom activities is highly recommended. ## Assessment methods

The final examination aims to assess the achievement of learning objectives and the ability of the student to solve real-world problems by writing C programs. The exam consists of two joint and mandatory parts: - Computer-based practical test: the student must solve one or more programming problems by writing working C code. The test also includes a specific exercise on number representation (number systems, base conversions, and encoding). This part evaluates the implementation of structures, logical efficiency, the absence of compilation/runtime errors, and the correct understanding of information encoding. The maximum duration of the practical test is 1 hour and 15 minutes. - Oral examination: critical discussion of the code developed during the practical test and verification of theoretical knowledge regarding computer science fundamentals, architecture, and C syntax. - Passing the practical test is strictly mandatory to gain access to the subsequent oral examination. - The practical test is non-conservative. A passing result on the practical examination shall remain valid exclusively for the current exam session. Accordingly, failure to register for the oral examination or failure to pass the comprehensive exam will result in the forfeiture of the practical exam grade; the student will therefore be able to retake both components of the exam starting from the subsequent session. - The result of the practical test will be communicated directly to the student via email or, alternatively, published on the official Department notice board within a few days of the test. Evaluation criteria: (i) Syntactic and semantic correctness of the submitted code; (ii) Logical efficiency of the developed algorithm; (iii) Correctness in solving the exercise on number representation; (iv) Proper use of technical terminology during the oral examination; (v) Ability to connect different topics of the course (e.g., memory management and pointers). The final evaluation is graded on a 30-point scale, where the practical test accounts for 60% and the oral examination accounts for 40% of the overall grade. Incoming international mobility students may choose to take the entire learning assessment (both the practical test and the oral examination) in English. Note for SLD/Disabilities: students with certified SLD or disabilities are invited to contact the teacher and the Department representative before the exam to agree upon extra time or specific compensatory/dispensatory tools according to university regulations.
