## Contents

The course is centered around the design and implementation of programs adopting the object-oriented programming paradigm. The underlying concepts of this paradigm are analyzed through the Python programming language. Specifically, the course program includes the following topics: - Object-oriented programming: concepts class, objects, methods and instance variables, message passing, encapsulation and information hiding, inheritance and polymorphism, interfaces and abstract classes, callbacks, static and dynamic binding, generic data types, abstract data types, quality criteria, UML class diagram; - Python programming language: language characteristics (interpretation vs. compilation, strong vs. weak typing), variables and data types (basic and structured), scopes, expressions and operators, flow control structures, functions, core data structures, I/O operations on file, exception handling, lambda functions, decorators, debugging tools, concurrency; - Programming for data processing and analysis: introduction to scientific and tensor computing, introduction to supervised and unsupervised machine learning, introduction to classification and regression models, introduction to training processes, pre-processing and cleaning of training data, Python libraries for data processing and analysis.

## Learning objectives

The course aims to study and analyze the object-oriented programming paradigm, its fundamentals and its use in software modelling of complex problems and systems, with particular focus on those relating to data processing via artificial intelligence techniques. Python is the reference programming language

## Prerequisites

Programmazione 1 is a prerequisite for this course. A good knowledge of the course content and, in general, of the basic concepts of programming is therefore required

## Teaching methods

The course includes lectures and practical exercises. The latter will cover both the design and implementation of programs and the training of classification and regression models using datasets provided by the professor

## Other information

The teaching materials will be available on the university's e-learning platform Handy Unisannio (https://handy.unisannio.it/)

## Assessment methods

The final exam consists of: - a practical test on the computer, which involves writing a program in Python language using the object-oriented paradigm; - an oral exam, which includes a discussion of the exercise covered in the practical test and questions on the theoretical topics covered in the course program.
