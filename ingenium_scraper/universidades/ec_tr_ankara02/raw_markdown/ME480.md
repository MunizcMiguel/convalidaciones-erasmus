### Objectives of the Course

To provide students with knowledge about nuclear power systems and nuclear reactions, and to make them understand the working principle and design differences between power plants.

### Course Content

Atomic And Nuclear Structure And Reactions, Neutrons And Their Interactions, Reactor Heat Generation, Heat Conduction In Reactor Elements, Nuclear Power Systems, Boiling Reactors, Pressurized-Water Reactors, Pressurized-Water Reactor Power Plants, Gas-Cooled Reactors, Gas-Cooled Reactor Power Plants, Fast-Breeder Reactors, Fast Breeder Reactors And Power Plants

## Weekly Detailed Course Contents

| Week | Topics | Study Materials | Materials |
|---|---|---|---|
| 1 | ATOMIC AND NUCLEAR STRUCTURE AND REACTIONS: Atomic structure, the structure of heavy atoms, the chemical reaction, energy from nuclear fission&fussion |  |  |
| 2 | ATOMIC AND NUCLEAR STRUCTURE AND REACTIONS: Conversion and breeding, energy from fission and fuel burnup, radioactivity, decay rates. |  |  |
| 3 | NEUTRONS AND THEIR INTERACTIONS: Neutron energies, fission and thermal neutrons, neutron flux and reaction rates. The 1/V region, the resonance region. |  |  |
| 4 | REACTOR HEAT GENERATION: Neutron conservation, heat generation rate in fuel, the fission energy in reactors, heat generated by a single fuel element. |  |  |
| 5 | HEAT CONDUCTION IN REACTOR ELEMENTS: Heat flow out of solid-plate-type fuel elements, cylindrical fuel elements and spherically shaped fuel. |  |  |
| 6 | NUCLEAR POWER SYSTEMS: The fusion reactor, neutron energy and moderation, fission power plants, gascooled- reactor power plants, fluid-fueled reactor. |  |  |
| 7 | BOILING REACTORS: Boiling reactor mass and heat balance, driving pressure in a boiling channel, average density in a boiling channel. |  |  |
| 8 | PRESSURIZED-WATER REACTORS: Materials for water reactors, steam generators, reactor-system pressurizers, chemical-shim control. |  |  |
| 9 | PRESSURIZED-WATER REACTOR POWER PLANTS: The shipping port atomic power station, the point beach reactor power plant, Pickering heavy-water power plant |  |  |
| 10 | GAS-COOLED REACTORS: Thermodynamic cycles; the direct open cycle, indirect open cycle and the direct closed cycle, gas-coolant radioactivity. |  |  |
| 11 | GAS-COOLED REACTOR POWER PLANTS: Analysis of the gas-steam system; the simple cycle, analysis of the gas steam system. The dual-pressure cycle. |  |  |
| 12 | FAST-BREEDER REACTORS: Nuclear reactions in fast-breeder reactors, conversion and breeding, the conversion (breeding) ratio. |  |  |
| 13 | FAST-BREEDER REACTORS: Nuclear reactions in fast-breeder reactors, conversion and breeding, the conversion (breeding) ratio. |  |  |
| 14 | FAST BREEDER REACTORS AND POWER PLANTS: Reactor plant arrangements, the Enrico Fermi nuclear power plant, the Sefor plant. |  |  |
