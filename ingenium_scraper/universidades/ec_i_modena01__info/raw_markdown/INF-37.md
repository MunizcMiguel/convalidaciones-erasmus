### Learning objectives

The course is part of the IT learning area for ICT and is aimed at providing knowledge of the basic principles of information processing systems and the fundamental skills for their use. The teaching carries out training activities aimed at facilitating professional choices. At the end of the course, the student will be able to apply the knowledge of software application development in any field, knowing how to integrate the knowledge of web technologies and the basic methods of artificial intelligence. ARTIFICIAL INTELLIGENCE: The course aims to provide knowledge and skills on the main machine learning and artificial intelligence techniques for the analysis of numerical data. This course will provide an introduction to the basic tools for solving machine learning problems both supervised and unsupervised. The course takes place with lectures and laboratory activities in python language through the numpy computation library. WEB TECHNOLOGIES: The course aims to provide knowledge and skills on methodologies and technologies for the design and development of modern applications based on Web and mobile infrastructures. The topics covered include Web technologies, as well as the development of web and mobile applications. Additionally, the course provides an introduction to Python programming and the Flask web application framework. The course consists of lectures introducing theoretical concepts and programming languages, alongside projects where students will apply what they have learned to real-world applications.

### Prerequisites

ARTIFICIAL NTELLIGENCE: A good knowledge of mathematical analysis and geometry is required. In addition, concepts from the statistics course will be used. WEB TECHNOLOGIES: Basic knowledge of database, SQL language, Java and Python is appreciated.

### Assessment methods

ARTIFICIAL INTELLIGENCE: The assessment will consist of a written exam with closed questions on the course content and formal aspects. A programming test will be performed on the exercises presented in class. The lab will be on/off while the mark is determined by the quiz in 30s. WEB TECHNOLOGIES The assessment consists of a written exam and an individual project. The written exam includes open-ended and multiple-choice questions designed to test the understanding of all course topics, as well as practical exercises to evaluate the knowledge and ability to build a Web application. The written exam is graded on a scale from 0 to 23 points; notes or other reference materials are not permitted during the exam. The project is an individual assignment requiring approximately three weeks of work. It involves designing and implementing a web application using technologies of the student's choice. Its goal is to assess the ability to apply knowledge and understanding, as well as independent judgment regarding the course topics. The project is graded on a scale from 0 to 10 points. For the evaluation, the student must prepare a maximum 8-minute PowerPoint presentation and discuss their design choices and code with the instructor, by booking an appointment. There are no midterm exams. FINAL GRADE: The overall grade for the integrated course will be the weighted average of the grades of the individual modules, rounded up (a grade of 30 cum Laude equals 30 for the calculation of the average). The final cum Laude honors for the integrated course will be awarded exclusively if the student achieves 30 in both modules, with cum Laude in at least one of the two (AI and Web Technologies).
