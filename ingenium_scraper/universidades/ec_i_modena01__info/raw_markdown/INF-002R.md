## Contents

Introduction and Information Representation (1 CFU) ------------------------------------------------- Information representation: positional number system, base 2, integer and fractional numbers. Bases 8 and 16, addition and subtraction of binary numbers, negative number representations, overflow and underflow. IEEE 754 standard, text representation, UNICODE. Architecture, Machine Language, and Assembly (1 CFU) -------------------------------------------- Computer architecture: Von Neumann machine, the ADE8 educational processor. The concept of variable, managing multiple data, the concept of array, data addressing. Elementary C Constructs (3 CFU) -------------------------- From assembly to C: structure of a C program, the concept of data type, integer and floating-point types, variable definition, identifiers, initialization, read-only variables. Functions, the main function, assignment. Left and right associativity, expression types. The goto statement and labels, the if statement. High-level programming. The do-while and for constructs. Pointers. Memory allocation: malloc, free, and realloc. Advanced Constructs and Multi-file Source Usage (2 CFU) ------------------------------------------------------ Allocating multiple data items: arrays. Accessing array elements with pointers and the square brackets operator. The C preprocessor. Structures in C: the struct directive. Defining structures and structure-type variables. Accessing structure members and passing a structure to a function. Defining new types: the typedef directive. Programming with Libraries and I/O (2 CFU) ----------------------------------------- The standard library. Overview of math.h and string.h headers. The concept of a file as an abstraction of the underlying hardware. The stdio.h library.

## Learning objectives

Aim of the course is to learn how to formalize and solve real world problems and how to describe them to a computer. Learn the basics of the C programming language.

## Prerequisites

None

## Teaching methods

Theoretical lessons and practical coding on computer in labs.

## Other information

Knowledge and understanding --------------------------- Through lectures, students learn the fundamental knowledge of computer science and in particular of imperative programming and acquire the ability to understand programs written in C language. Applying knowledge and understanding ------------------------------------ Through practical exercises on the computer, the student is able to define sequential algorithms and to develop and verify programs using the C programming language. Making judgments ---------------- Through the test, the student learns to quickly analyze part of a computer program evaluating what is essential in order for an algorithm to work. Laboratory testing leaves complete freedom to choose the solution that is deemed suitable in order to comply with the proposed problem requirements. Communication skills -------------------- The course and quiz tests require to develop considerable attention to the rigor in the language in referring to specific elements of the programs. Learning skills --------------- The described activities allow the student to acquire the methodological tools to continue their studies and to be able to arrange their own update.

## Assessment methods

For each session there are two tests: theory test and programming test. The theory test lasts 1 hour and consists of a quiz test. You cannot use any didactic material, nor the calculator. There are 20 questions, each with 4 possible answers, only one of which is correct. Each correct answer gives 1.65 points, each wrong answer takes away 0.55 points. Answers not given do not change the score. The grade is calculated by rounding to the nearest integer, with 0.5 upwards. If the test takes place in presence, the answers must be uploaded to the website indicated on the test within the deadline specified during the examination. If the test is carried out online, the answers are automatically acquired by the system and you do not need to do anything else. The programming test lasts 2 hours. It is allowed to carry and use only one textbook (no exercise book, no photocopies, no notes, no loose sheets, no spiral bound sheets or other). The references provided in class will be on the exam site. No access to Internet sites will be allowed. Any attempt to access the submission system during rehearsal hours from outside will be considered an attempt to copy and as such sanctioned. Sign up for the theory and programming tests if you intend to take one or both tests. Do not wait to know the result of the theory test before signing up for the programming one. The deadlines to register are mandatory, so if you are not registered for the test, you cannot take it. There are no exceptions for any reason. This means that if you are not on the list on the day of the exam, you will not be added. Make sure you have signed up for the right exam and the correct test. Show up about 15 minutes before the start of the test with your university card. Once the trial has started, you will no longer be able to log in. Those who do not have a university card with them will not take the test. It is not possible to leave the classroom (when in attendance) before the end of the test for any reason, even if you finished the task early. In case of remote tests, it is necessary to connect to the videoconferencing system with a mobile phone positioned horizontally (activate the rotation) and laterally so that it frames the workstation (keyboard, hands, torso and screen). It is not important that you see the screen content well, because that must be shared with the screen sharing system of the site https://olj.ing.unimore.it Both tests are evaluated with a maximum score of 33. Passing, as per Italian university standards, is achieved with a grade greater than or equal to 18. The written exam must be passed (grade>=18) in order to access the programming test. The final grade will be the weighted average (rounded to the nearest integer, 0.5 upwards) of the grades of the two tests, where the theory weighs 1 and the programming weighs 2. Honors are obtained if the final grade after rounding is 31 or more. The written test, once passed, remains valid until the start of the new course in September of the year following the start of the course. Therefore, those who pass the theory test at the first session can take the programming test many times. Those who pass the theory test at the last session (in September) have only one chance to pass the programming one.
