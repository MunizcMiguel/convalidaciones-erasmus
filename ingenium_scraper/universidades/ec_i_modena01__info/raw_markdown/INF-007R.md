## Contents

The course aims to make students acquire the concepts, algorithms, and methodologies of structured programming in the C language. Activation record (1 CFU) Function activation records, stack memory, rules of visibility and duration of variables and functions, global and static variables. Dynamic memory allocation. Modular organization of programs. Recursion (3 CFU) Recursive algorithms, recursive functions. Backtracking algorithms. Structured data types. Complexity Complexity of algorithms, asymptotic behavior, evaluation of the complexity of programs. Greedy algorithms. Search and sorting algorithms. Abstract data types. (2 CFU) Lists, stacks, queues, heaps. Binary and Search Trees (BST): insertion, search, deletion. Dictionaries: management and implementation with Lists, BSTs, and Heaps. Exercises (3 CFU) The course includes classroom and laboratory exercises on all the topics covered in class. In addition, topics concerning the design and implementation of structured programs in C language will be studied through assisted exercises in the teaching laboratory.

## Learning objectives

To introduce the basic concepts of the structured programming, the methodologic aspects of the programming and the algorithm correctness and complexity.

## Prerequisites

Students need to have attended the course of "Fondamenti di Informatica I e Lab." and have a good knowledge of the C programming language.

## Teaching methods

The course is taught through lectures supported by slides (available to the students via the moodle platform) and practical classes in the laboratory. The lectures are intended to provide insight into the "theoretical" foundations of the area. For each topic are also made available through the olj.ing.unimore.it platform some examples of programs to be carried out in the laboratory.

## Other information

1. Knowledge and understanding: The lectures will provide the student with the ability to know and understand the computer science fundamentals and the imperative and sequential programming. 2. Ability to apply knowledge and understanding Through the practical lessons in the laboratory, the student will be able to define sequential algorithms and to develop and test programs using the C language. 3. Making judgments The student will be able to design and implement complex computer application in C language. 4. Communication skills The student will be able to communicate ideas, problems, and complex computer solutions. 5. Learning skills The student will have a basic understanding that will allow subsequent searches on topics related to software programming and analysis of complex data structures.

## Assessment methods

Learning is verified through a multiple choice test (1 hour and 3 CFU) in preparation for a second practical computer test (2 hours and 6 CFU). In the first test the student must demonstrate that they have acquired the knowledge regarding the course content. In the computer test, the student must demonstrate the ability to create algorithms in C language similar to those seen during the course. For the first test it is not possible to consult notes, books or other material, for the second test it is possible to consult theory books, but not notes or exercise books, it is also allowed to make use of the C reference, the documentation and the implementation of the primitive functions that will be provided during the exam. There are no intermediate tests.
