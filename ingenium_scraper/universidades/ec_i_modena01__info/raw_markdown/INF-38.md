## Contents

The course focuses on issues related to communication in computer systems connected through local or geographic networks. In particular, the course provides an in-depth study of TCP/IP suite protocols, Internet architecture and routing mechanisms, client/server paradigm, naming (case study: DNS system), and basic network applications, with particular attention to the World Wide Web. The course layout is divided in three main parts: 1) Protocols (3CFU) - Introduction to networks and protocols - TCP/IP Stack - IP level: Autonomous systems, Internet routing algorithms, router architecture - Domain Name System: name servers, resource records, resolution modes, zones - Transport level: theory, UDP protocol, TCP protocol, congestion control 2) Network applications (3CFU) - Application level - World Wide Web: client, server, HTTP protocol, URL - e-mail and file transfer services - Network-oriented performance and monitoring - Introduction to computer security 3) Lab experiences (3CFU) - Network configuration and analysis in GNU/Linux systems - Socket programming in C and Python

## Reference texts

## Learning objectives

The course provides basic knowledge on architecture and protocols of computer networks. The focus is on the TCP/IP protocol stack. The Lab portion of the course provides the know-how that allows the deployment of main network services based on Linux/Unix systems as well as network security.
