## Contents

The syllabus covers Java fundamentals, including data types, operators, control structures, methods, arrays, strings, and unit testing with JUnit (1 ECTS credit). Object-oriented programming covers classes, encapsulation, inheritance, polymorphism, interfaces, abstract classes, and composition (1 ECTS credit). The course then addresses the Java Collections Framework, generics, exception handling, and resource management (1 ECTS credit). Functional and concurrent programming covers lambda expressions, the Stream API, threads, synchronization, and concurrent task management (1 ECTS credit). Lab work covers graphical user interface development with JavaFX (1 ECTS credit), along with accessing PostgreSQL databases through JDBC, developing REST services with Spring Boot, and integrating them with JavaFX clients (1 ECTS credit). The detailed syllabus is available on https://github.com/n[docente]/learn-java-core.

## Reference texts

The reference materials are the course notes provided by the instructor and Big Java: Early Objects, 7th edition, by Cay S. Horstmann, published by Wiley.

## Learning objectives

The course introduces the principles of object-oriented programming using Java. Its aim is to give students the knowledge and skills they need to independently design, develop, and test Java applications using established software development practices. The course explores collections, functional programming, and concurrency. In lab sessions, students develop desktop applications that integrate graphical user interfaces, relational databases, and REST services.

## Prerequisites

A basic understanding of programming is recommended, particularly familiarity with variables, data types, control structures, and functions. No prior knowledge of Java or object-oriented programming is required.

## Teaching methods

The course is organized into weekly modules. Each module covers a specific topic and includes a laboratory component. The course is delivered through lectures and in-class practical exercises supported by projected teaching materials (slides). Attendance at in-person lectures is not mandatory. The course is taught in Italian.

## Other information

Knowledge and understanding By the end of the course, students will understand the main constructs of Java and the principles of object-oriented programming. They will be able to read and understand Java code, model a problem, and design, develop, and test a software solution. Independent judgement Students will be able to compare alternative solutions, select appropriate methods and tools, and justify their design decisions. They will be able to critically evaluate code and suggestions produced by AI assistants and verify that they are correct and appropriate for the problem. Communication skills Students will be able to describe how software works and explain their design decisions using appropriate technical terminology. Learning skills Students will be able to consult technical documentation, deepen their understanding of course topics, and independently explore new software development tools.

## Assessment methods

Assessment consists of a paper-based written exam and an individual take-home project. Students are required to use AI assistants to complete the project and to follow the instructions published on the course website. The written exam consists of ten multiple-choice or short-answer questions. Each question is worth 3 points, for a total of 30 points. The project can raise or lower the written exam score by up to 3 points, depending on whether it is assessed as above or below average.
