## Contents

The course aims to provide basic theoretical knowledge of modern operating systems, as well as solid skills in the use and administration of Unix-like systems through the command line. 1. Theoretical Foundations of Operating Systems (3 ECTS) 1. Overview of operating systems (monolithic, modular, microkernel, distributed architecture) 2. Processes, threads, system calls 3. Compilation process, symbols, linking, and libraries 4. Scheduling (including kernel-level scheduling) 5. Process hierarchy 6. Synchronization and deadlock 7. Synchronization primitives (semaphores, mutexes, shared memory, pipes, sockets, signals) 8. Memory hierarchy 9. Mass storage, filesystems 10. System memory (segmentation, paging, virtual memory, hardware support) 2. Bash (3 ECTS) 1. Introduction to the command line and bash 2. Input and output management (pipes, redirection) 3. Basic commands (man, cd, ls, echo, su, sudo ...) 4. Filesystem interaction (mkdir, pwd, find, chown, chmod, ...) 5. Text input processing (grep, awk, sed, cut, cat, ...) 6. Scripting (variables, data types, operations, if statements, loops, tests, ...) 3. System Administration Commands (3 ECTS) 1. System monitoring (ps, top, df, du, ...) 2. User management (adduser, usermod, passwd, ...) 3. Mass storage management (fstab, mount, ...) 4. Networking utilities (ping, curl, wget, ssh) 5. Archive management (zip, tar) 6. Task scheduling (cron) 7. Service management (System V, systemd) 8. Software package management – focus on apt

## Reference texts

## Learning objectives

The course provides both theoretical and practical foundations for understanding the functioning of modern operating systems, with a particular focus on Unix-like systems. Students will acquire knowledge of key concepts in operating system architecture (processes, memory, file systems, synchronization) and develop practical skills in using the Bash shell for system administration and automation. The course is designed to build a solid theoretical background along with hands-on competencies that are immediately applicable in academic and professional contexts.

## Prerequisites

- C programming language

## Teaching methods

- In-person lectures in the classroom - Practical exercises in the lab or in an equipped classroom (students are required to use their own laptop)

## Other information

Theoretical Knowledge - Understand the architecture of modern operating systems (monolithic, modular, microkernel, distributed). - Describe the lifecycle of a process and the role of threads and system calls. - Analyze scheduling strategies, memory management, and synchronization mechanisms. - Understand the structure and functioning of filesystems and virtual memory. - Recognize key mechanisms of interaction between kernel and user space. Practical Skills - Use the Bash shell to run system commands, process text data, and automate tasks. - Develop complete Bash scripts using variables, control structures, and advanced commands. - Administer a Unix-like system: user management, permissions, processes, services, and software packages. - Monitor system status and troubleshoot issues using appropriate tools. - Use networking tools for remote interaction and diagnostics (ssh, ping, curl, etc.).Obiettivi sviluppo sostenibile

## Assessment methods

- Written exam to assess theoretical knowledge, consisting of both multiple-choice and open-ended questions. - Lab exam focused on developing Bash scripts that incorporate the commands covered in class. - The final grade is calculated as the arithmetic mean of the two exam scores. Both exams must be passed within 150 days.
