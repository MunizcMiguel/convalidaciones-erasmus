# Data Transmission

## Type of Course Unit

Optional

## Level of Course Unit

First Cycle

## Semester when the Course Unit is delivered

Summer Semester

## Mode of Delivery

Face-to-face

## Language of Instruction

English

## Prerequisites and Co-Requisites

Course succeeds to compulsory courses of previous semester

## Summary

Data chain for data transferring; transmission method and security messages; parameters and data signal characterization; modulation manners and data signal demodulation; terminal equipment for data transferring; data signal transducer in baseband; HDSL transducer, telephone modems; broadband, cable and ADSL modems; coupling resources for data transferring; LAN fundamental characteristics.

## Learning Outcomes of the Course Unit

Understand telecommunication protocols and their security in the data transfers.

Learning outcomes are set so that the students are able to identify and apply tasks in data transition field.

## Course Contents

Lectures:

Data chains for data transmission. Basic terms.

Alphabets and codes.

Data trasmission and message security.

Parameters and characteristics data signals.

Modulation and demodulation data signals.

Data terminating equipment for data transmission.

Baseband modems.

HDSL modems. Telephone modems.

Broadband, cabel and ADSL modems.

Multiplexing for data transmission.

Fundamentals of LANs.

Data networks with switched networks.

Data networks with packed networks.

Frame relay networks.

Exercises:

Amount of information in message, information entropy.

Aritmethic operation with polynoms, CRC checksum.

Test n.1 - security data transmission.

Statistical compression methods.

Dictionary compression methods.

Test n.2 - data comprression.

Laboratories:

Data transmission with analog modems.

Data transmission with modern technologies of xDSL.

Wireless data transmission.

Wireless security data transmission.

Security data transmission.

Projects:

Cryptography methods for data transmission.

Compression methodds for data transmission.

Computer labs:

Introduction to Linux, ASCII table.

Basic commands in Linux.
