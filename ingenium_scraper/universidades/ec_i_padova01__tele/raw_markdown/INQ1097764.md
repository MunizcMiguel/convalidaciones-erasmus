## Prerequisites

The course has no prerequisites.

## Learning objectives

Knowledge of computer operating principles, object-oriented programming, elementary problem-solving approaches (algorithms), and data structure design skills. Development of the skills needed to develop simple applications in the Java programming language.

## Innovative teaching methods: Teaching and learning strategies

- Problem solving - Case study - Problem based learning - Use of technological tools (moodle and/or other educational tools, software, videos, quizzes, wooclap) - Feedback - Assessment activities during the course

## Examination methods

There is a single written test divided into two distinct parts: - a multiple choice questionnaire (40-50 questions in 40-50 minutes) - a programming test in Java (1-2 hours) Normally the two parts are executed on a computer. An oral test is not normally foreseen. The teacher may, at his discretion, ask some students to take an oral test. To obtain the special grade 30 cum Laude, students are normally required to take, in addition to the written exam, also the oral exam.

## Assessment methods

The assessment of the student's preparation is based on the understanding of the topics covered and the ability to apply them independently in the development of simple applications in the Java language.

## Contents

Architecture of a computer. Central processing unit, central memory, mass storage devices, input and output devices. The operating system, summary of functions, processes, multi programming. Representation of information, numbering systems and conversions. Programming languages. Execution of a program by compilation and/or interpretation. The Java virtual machine. Concept of algorithm, introduction to the analysis of algorithms, examples of problems and their computational sizes. Measurement of complexity: in the worst case and in the average case. Big-O asymptotic notation. Recursion, elimination of recursion. Data structures and algorithms, the concept of abstract data type, a Java interface as a definition of an abstract data type, realization of an abstract data type by means of a class. Arrays, lists, stacks and queues, realization by means of an array or a linked list. Search for an element in an array and in a list. Search by bisection in a sorted array. Tables, maps, multi-maps, simple implementation of a map/multi map using a partially filled array or a list. Sorting algorithms, sorting by selection, insertion, mergesort. The Java programming language. Elementary data types and objects, references, operators and expressions, control statements, classes and interfaces. Fields and methods of a class. Polymorphism and inheritance. Elementary error management. Introduction to object-oriented programming. Input and output operations from standard input and output, input and output operations from text files.

## Teaching methods

Lectures, supervised programming training, and guided programming training (laboratories) in presence. During the supervised and guided programming, exercises of increasing difficulty are proposed to prepare students for the objective of independently developing applications in the Java language. Supplementary teaching is also provided for the in-depth study of relevant computer science topics.
