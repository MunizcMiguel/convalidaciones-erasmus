## Prerequisites

Basic knowledge of calculus 1, linear algebra, probability theory, algorithm design, and fundamental elements of programming.

## Learning objectives

The aim of the course is to provide the basic concepts of machine learning, introduce some fundamental algorithms to address classification, regression, and clustering problems, and to qualitatively and quantitatively analyze the results of an experiment. At the end of the course, the student will be able to: - understand the fundamental principles and main methodologies of machine learning; - analyze cases of supervised and unsupervised learning; - design and implement software systems capable of solving the considered problems; - evaluate the effectiveness of the chosen methodology for solving a given problem.

## Assessment methods

The evaluation of the acquired knowledge and skills will be based on: - The completeness of the acquired knowledge; - The ability to solve a learning problem using the proposed techniques; - The correct use of technical terminology; - Originality and independence in identifying the most suitable methodologies to solve a specific learning problem; - The ability to interpret results in a practical learning problem.

## Contents

1) Python - Introduction to the programming language. - Use of Python for data analysis. - Empirical study of the behavior of random variables. 2) Introduction to Machine Learning (ML) Instances, features, labels, training set, test set, goal, generalization error, empirical risk minimization, overfitting, evaluation. Types of machine learning. 3) Unsupervised Learning: Clustering - Concept and formalization. - k-means clustering: Lloyd’s algorithm. - Linkage-based clustering. - Gaussian mixtures and estimation via Expectation-Maximization (EM). - Clustering case studies and implementation in Python. 4) Supervised Learning: Classification - Linear models for classification: formal definition, examples; Perceptron algorithm. - Formalization for a finite hypothesis class. Introduction to Probably Approximately Correct (PAC) learning. - Classification case studies and implementation in Python. 5) Supervised Learning: Regression - Introduction, linear regression, and polynomial regression. - Regression case studies and implementation in Python. 6) Evaluation - Validation, validation for model selection (Train-Validation-Test split, k-fold cross-validation) - Statistical significance, Maximum Likelihood Estimation (MLE), and confidence intervals.
