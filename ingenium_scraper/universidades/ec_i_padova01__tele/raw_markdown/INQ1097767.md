## Learning objectives

COURSE DESCRIPTION: the course introduces the fundamental principles underlying the design and analysis of digital circuits, with a focus on the processing of binary information and basic hardware architectures. Students will learn how to represent and manipulate data in digital format, how to design combinational and sequential circuits, and how to describe digital systems using a hardware description language (VHDL). LEARNING OBJECTIVES: by the end of the course, students will be able to: 1) Represent information in a format that can be processed by a computer. 2) Manipulate logical expressions and functions, minimize them through algebraic and Karnaugh-maps optimization method, and translate high-level functional specifications in the form of logic functions. 3) Design a combinational logic circuit, understand the basic architectures of binary adders, and have familiarity with the concept of performance optimization through appropriate architectural choices. 4) Translate an abstract problem of medium complexity into the formulation of a finite state machine. Synthesize a realization in the form of a combination of logic gates and registers. 5) Understand the main dynamic limitations of a medium complexity digital system. 6) Understand the concept abstraction level and represent medium-complex systems as a combination of subsystems of lower complexity. 7) Describe digital systems in VHDL, describe a system at different abstraction levels and organize the description of complex systems in various hierarchical levels. 8) Understand the organization and the main functions of a computing architecture. 9) Identify potentials and limits of a given type of memory, depending on the application context. 10) Apply priority techniques and communication protocols in the management of shared resources. 11) Describe the instruction flow within a computer. 12) Evaluate the different approaches for the management of asynchronous events in computers.

## Contents

- Analog and digital signals, binary digital systems, block diagram of a computer and a microcomputer, description of the abstraction levels in the design of a digital system, design flow. - Binary representation of numerical and non-numerical information. - Boolean algebra: properties and fundamental theorems. - Concept of logic operator and logic gate. Difference between ideal and real logic gate. - Normal forms, minimization of two-level logic functions with the use of Karnaugh maps. - Design of combinational logic: basic combinational blocks and hierarchical system design. Arithmetic blocks, binary adders and subtractors. - Concept of sequential system, state variables and representation as a combination of combinatorial system and memory elements. Latches and flip-flops. - Analysis and synthesis of a finite state machine. Basic elements of temporization and main dynamic limits of a sequential system. - Overview of the implementation technologies for digital systems and programmable logic devices. Memory basics. - Registers, register transfers, digital systems partitioned in control unit and datapath. Microoperations and register transfer language. Shift registers and counters. - VHDL language for the representation (at different abstraction levels) and logic simulation of digital systems. - Organization of a computer: datapath, memory, control unit, arithmetic-logical unit, input/output devices. - Computer architecture: machine instructions, addressing methods, calls to subroutines, dynamic memory allocation. - Memory organization: cache memory, virtual memory, memory mapping, and management unit (MMU). Direct memory access (DMA). - Interruption systems: context switching, acknowledgment of outages, external interruptions, and software.
