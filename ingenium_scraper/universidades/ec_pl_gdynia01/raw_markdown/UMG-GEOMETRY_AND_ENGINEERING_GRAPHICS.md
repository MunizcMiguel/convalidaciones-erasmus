# Geometry and engineering graphics

- ECTS: 2
- Plan semester: 1 (fall term)

## Course description

Overview of basic AutoCAD functions and tools. Creating a project in AutoCAD Electrical and discussing the basic functions and tools required for working in this environment. Creating a project in AutoCAD Electrical, inserting a drawing table, inserting a ladder, and creating wire connections between individual points, inserting components and drawing wire connections between them
