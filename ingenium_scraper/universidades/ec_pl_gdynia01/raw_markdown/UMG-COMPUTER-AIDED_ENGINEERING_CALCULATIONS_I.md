# Computer-aided engineering calculations I

- ECTS: 2
- Plan semester: 2 (summer term)

## Course description

Components of the MATLAB-Simulink programming environment. Using available tools: editor, Live Editor, debugger, parser, profiler. Alternative methods of accessing MATLAB. Solving ordinary differential equations in MATLAB and Simulink. Modeling dynamic systems. Executing a cycle of programming tasks in the MATLAB, Simulink, and MATLAB- Grader environments.
