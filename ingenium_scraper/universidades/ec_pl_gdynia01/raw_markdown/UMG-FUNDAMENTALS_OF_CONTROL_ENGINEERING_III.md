# Fundamentals of Control Engineering III

- ECTS: 4
- Plan semester: 4 (summer term)

## Course description

Electric, mechanical, pneumatic and hydraulic elements and devices control systems. Pneumatic continuous PID controllers. Pneumatic and hydraulic executive devices. The dynamic properties investigations of the control object. The identification of the control object. Manual tuning of the continuous PID controller. The control system synthesis with the method state variable with poles positioning of closed-loop system.
