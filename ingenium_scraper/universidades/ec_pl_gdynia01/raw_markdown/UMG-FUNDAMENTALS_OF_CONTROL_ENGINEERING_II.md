# Fundamentals of Control Engineering II

- ECTS: 2
- Plan semester: 3 (fall term)

## Course description

Dynamic correction of control systems. Composite control systems. Digital control systems. Non-linear control systems. Extremal regulation. Optimal control. Adaptive control. Game control.
