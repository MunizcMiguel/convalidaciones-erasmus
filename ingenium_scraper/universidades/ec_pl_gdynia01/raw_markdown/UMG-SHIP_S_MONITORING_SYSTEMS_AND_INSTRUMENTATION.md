# Ship's Monitoring Systems and Instrumentation

- ECTS: 3
- Plan semester: 5 (fall term)

## Course description

Types of engine room and deck monitoring systems. Measurement and executive line used in monitoring and control systems. Sensors. Transducers analog and programmable (HART). Diagnostic, repairing, calibration, commissioning of measuring temperature, pressure, level etc. Electronic ship's fire monitoring systems.
