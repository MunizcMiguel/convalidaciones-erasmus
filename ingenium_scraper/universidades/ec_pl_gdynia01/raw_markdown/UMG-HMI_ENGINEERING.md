# HMI Engineering

- ECTS: 1
- Plan semester: 5 (fall term)

## Course description

HMI destination and application. HMI communication basics: HMI-PC, HMI-PLC. Editing and presentation of PLC variables on HMI. Lamps, Numeric and Message Displays. Switches, keypads. Screens, graphics, functional switches. Alarm windows, animation, scripts. Examples: interfaces for wave generator, drive control. Synthesis of an control system with PLC, touch panel.
