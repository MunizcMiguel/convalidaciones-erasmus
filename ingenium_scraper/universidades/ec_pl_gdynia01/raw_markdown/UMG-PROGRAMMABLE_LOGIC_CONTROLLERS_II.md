# Programmable Logic Controllers II

- ECTS: 1
- Plan semester: 5 (fall term)

## Course description

Combinational logic, sequential logic. Digital control systems. Sequential control, Moore and Mealy machine, process controlled and time controlled systems. Description of control systems: states, system variable, transitions, output functions. Control system synthesis. Programming of drive control, system testing by DC motors and 3-phase drives.
