# Microprocessor Control Systems II

- ECTS: 2
- Plan semester: 3 (fall term)

## Course description

Microcontrollers programming in C language. Typical components of the microprocessor system. Data buses: RS 232, RS 422, RS 485, I2C, CAN, USB. 16 and 32-bit microcontrollers. Evaluation microprocessor system. Compiling and linking of programs in C. Microcontroller ports. Self-realization of complex program using the previously known components.
