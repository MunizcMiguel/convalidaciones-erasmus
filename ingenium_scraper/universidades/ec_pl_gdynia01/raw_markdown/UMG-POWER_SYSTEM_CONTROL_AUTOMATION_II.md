# Power System Control & Automation II

- ECTS: 1
- Plan semester: 5 (fall term)

## Course description

Visualization of ship power system. SCADA Systems, PLC programming. Simple computation, data processing computers, wired type & stores programmed type computers, computer control (AI, AO, DI, DO). Application of computers on merchant ships for performance monitoring & maintenance data.
