# Marine Power System - Control & Automation

- ECTS: 1
- Plan semester: 5 (fall term)

## Course description

Automation of Ship Electrical Power Plant and Auxiliary systems. Diesel generators. Shaft generator. Turbo generator. Shore supply. Emergency generator. Main switchboard. Emergency switchboard. Consumers. Feeders. Earth Monitoring etc.
