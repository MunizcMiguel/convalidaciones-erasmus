# Numerical Methods

- ECTS: 2
- Plan semester: 2 (summer term)

## Course description

Number Systems. Interpolation and approximation, orthogonal series, an introduction to wavelet. Basic numerical methods for: solving linear and nonlinear algebraic equations, solving differential equations, searching the extreme, and other selected methods.
