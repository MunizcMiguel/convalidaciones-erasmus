# Computer Area Network

- ECTS: 2
- Plan semester: 7 (fall term)

## Course description

Origins of computer networks. Organization of the ISO OSI reference model. The signals in the network and transmission media. Network topologies. Hardware resources and organization of the network. The basic properties of selected local networks. IEEE 802 Standards. Ethernet, types, media, methods of access to the communication channel. Upper layer protocols, TCP / IP stack. Network operating systems and utilities. Network administration. Safety.
