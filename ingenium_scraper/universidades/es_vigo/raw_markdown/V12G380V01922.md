| Otros comentarios sobre la Evaluación |  |  |  |  |  |  |
| La evaluación de la materia se realizará con las siguientes pruebas y actividades: a) La asistencia y participación activa se puntuará con un 1 sí se ha asistido a toda las clases de teoría y de práctica. Se permite una falta sin justificar y solo se admitirán justificantes médicos originales con la firma y el número de colegiado del médico, además del sello del centro médico. Si el justificante no tiene todos estos datos no considerara la falta como justificada. En el caso de faltar a más de una clase sin justificar se puntuará con un 0. b) Un trabajo/problema práctico a resolver por el alumno en la casa, que se puntuará sobre 1. c) Una prueba de conocimiento de la Normativa y resolución de un problema que se desenvolverá durante la semana de pruebas de evaluación continua. Se puntuará por separado la Normativa y el problema sobre un total de 4. d) El examen final consistirá en otra prueba de Normativa y resolución de un problema que se desenvolverá en la fecha asignada por la escuela para los exámenes finales. Se puntuará por separado la Normativa y el problema, sobre un total de 4. Para poder superar la materia será necesario obtener en la suma de las notas de las pruebas de Normativa un 30% de la puntuación total, y en la suma de las notas de las pruebas de problemas un 40% de la puntuación total. Si no se alcanza la puntuación mínima en las pruebas c) y/o d) la puntuación máxima da asignatura será de 390 puntos sobre 10. En la segunda oportunidad se repetirán las pruebas c) y d), unificando la prueba de Normativa por una parte y la de problemas por otra, manteniéndose las puntuaciones obtenidas en a) y b), salvo renuncia expresa a estas, puntuándose entonces solamente las pruebas c y d). No se permitirá la utilización de ningún dispositivo electrónico durante las pruebas de evaluación salvo autorización expresa. El hecho de introducir un dispositivo electrónico no autorizado en el aula el día del examen será considerado motivo para la no superación de la materia en el presente curso académico y la cualificación global será de suspenso (0,0). Compromiso ético: Se espera que el alumno presente un comportamiento ético adecuado. En el caso de detectar un comportamiento no ético (copia, plagio, utilización de aparatos electrónicos no autorizados, y otros) se considerará que el alumno no reúne los requisitos necesarios para superar la materia. En este caso la cualificación global en el presente curso académico será de suspenso (0.0). |  |  |  |  |  |  |
