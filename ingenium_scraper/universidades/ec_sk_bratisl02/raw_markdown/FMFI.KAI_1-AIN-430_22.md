## Learning outcomes

Introduction to three programming paradigms: Concurrent programming, Functional Programming,
Logic Programming

## Class syllabus

- Brief history of programming languages
- Introduction to programming paradigms
- Concurrent programming in GO
- Functional programming in Haskell
- Logic programming in Prolog
- Constraint logic programing CLP
