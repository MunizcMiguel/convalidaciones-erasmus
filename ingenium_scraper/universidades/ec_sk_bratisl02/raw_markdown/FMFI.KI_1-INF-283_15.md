## Learning outcomes

Students will be familiar with basic terminology of computer networks and principles of their
operation. They will have practical experience with usage and configuration of technologies
commonly used on local networks and on the internet.

## Class syllabus

Basic network terminology, layer models, OSI, TCP/IP
Physical layer - cables, wireless transmission
Data link layer - Ethernet, WiFi.
Network layer – IP, routing, ICMP, ARP.
Transport layer – UDP, TCP, NAT.
Application layer – DNS, DHCP, Web, Mail, FTP, ...
IPv6
Security – firewall, VPN, SSL/TLS, security at the application layer (Web, Mail).
