# Efficient Algorithms and Data Structures (FMFI.KAI/1-AIN-105/22)

## General information

- Type of activities: lecture / practicals
- Number of hours:
- per week: 4 / 2 per level/semester: 52 / 26
- Form of the course: on-site learning
- Number of credits: 8
- Recommended semester: 3.
- Educational level: I.

## Educational activities

Prerequisites: FMFI.KAI+KDMFI/1-AIN-170/22 - Programming (2) and FMFI.KAI/1-
AIN-121/22 - Discrete Mathematics (1)

## Course requirements (assessment)

Continuing evaluation: homework assignments (30%), midterm (20%)
Exam: written with oral consultation (50%)
To succesfully complete the course, student has to obtain at least 50% of points on the final exam
Final grade: A 90%, B 80%, C 70%, D 60%, E 50%
Scale of assessment (preliminary/final): 50/50

## Learning outcomes

Students will learn the basics of data structures and will be able to use basic methods of designing
efficient algorithms. They will be able to work with basic concepts of computational complexity.

## Class syllabus

Computational complexity. Sorting algorithms. Priority queue. Dictionary. Text search. Methods
of designing efficient algorithms (greedy algorithms, dynamic programming, divide and conquer).
Representations of graphs and elementary graph algorithms. NP-hard and NP-complete problems.

## Recommended literature

Data Structures and Algorithms in Python / Michael T. Goodrich, Roberto Tamassia, Michael H.
Goldwasser. John Wiley & Sons, 2013.
Introduction to algorithms / Thomas H. Cormen ... [et al.]. Cambridge, Mass. : MIT Press, 2001
Programming pearls / Jon Bentley. Reading : Addison-Wesley, 1986
