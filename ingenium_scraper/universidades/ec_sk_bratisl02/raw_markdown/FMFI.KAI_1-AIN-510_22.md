## Learning outcomes

Graduate:
- knows the principles of operation of the GNU/Linux operating system
- knows and understands the basic principles of GNU/Linux OS components such as process, file
system, user management, access rights, ...
- recognizes and applies a set of commands according to administration-user scenarios
- knows and understands the basics of the network model
- applies encryption principles in GNU/Linux OS
- creates a "oneline compound command" or script to solve an administrative-user task
- creates a simple Makefile

## Class syllabus

- Virtual machine and package system
- File system
- Logical Volume Manager
- Redundant Array of Inexpensive Disks (RAID)
- File and directory rights system
- Processes
- Connecting computers and the Internet
- TCP and UDP transport layer network model
- Encryption, keys and ssh
- System initialization
- Apache and MariaDB
- Compiling and GNU Make
