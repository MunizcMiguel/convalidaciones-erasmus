# Web Applications (1) (FMFI.KDMFI/1-AIN-189/22)

## General information

- Type of activities: lecture / practicals
- Number of hours:
- per week: 2 / 2 per level/semester: 26 / 26
- Form of the course: on-site learning
- Number of credits: 6
- Recommended semester: 2.
- Educational level: I.

## Prerequisites

Recommended prerequisites:
1-AIN-112 Introduction to web technologies
Antirequisites: FMFI.KZVI/1-AIN-615/00

## Course requirements (assessment)

Intermediate assessment: practical assignments, project (max 20%)
Exam: practical (at least 70% of the semester points are needed)
Indicative evaluation scale: A 90%, B 80%, C 70%, D 60%, E 50%
Scale of assessment (preliminary/final): 20/80

## Learning outcomes

After completing the course, students will be able to create a simple server-side web
application with personalized access to individual parts of the application. The data will be
stored in a database.

## Class syllabus

- Server-side web applications
- Introduction to PHP
- Basic language structures (1)
- Variables, constants, strings, operators, conditions, loops
- Basic language structures (2)
- working with date and time, arrays, functions to work with arrays and strings
- Reusing code
- Form processing, input processing and treatment
- SESSION, COOKIES
- Introduction to working with a database
- Basic database queries
- SELECT, INSERT, UPDATE, DELETE
- Linking PHP to the database
- Working with multiple tables at the same time
