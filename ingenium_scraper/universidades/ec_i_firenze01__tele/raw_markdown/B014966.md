## Learning objectives

The course aims to introduce mathematical programming problems and provide skills on the main mathematical properties of this class of problems. In particular, linear programming problems, network flow problems, mixed integer linear programming problems and nonlinear programming problems are addressed, analyzing their particular geometric and analytical properties. Algorithms and methodologies for their solution are then introduced.

## Contents

Linear programming models: allocation models and blending models.  
Fundamentals on linear programming. The simplex method.  
Network flows models. The minimum cost flow and the network simplex method.  
Mixed integer linear models. Use of binary variables to model logical constraints.  
Nonlinear programming models. Optimality conditions. Introduction to the Support Vector Machines.

## Extended programme

The course focuses on some classes of optimization problems, their main mathematical properties and numerical solution methods. The first half of the course is dedicated to linear programming. Polyhedral geometry topics are covered, such as the mathematical characterization of the vertices of a polyhedron. Starting from the fundamental theorem of linear programming, the simplex algorithm is introduced and developed, introducing the concepts of basic feasible solution and the sufficient criteria of optimality and unboundedness. Furthermore, duality theory topics are explored in depth, leading to the definition of complementarity conditions for linear programming. At the same time, resource allocation, mixing and transportation models are introduced as examples of linear programming problems. Subsequently, networ flow models are introduced. Starting from basic concepts of graph theory, we arrive at the formulation of the minimum cost network flow problem and the definition of the network simplex algorithm. In the need to insert logical constraints within linear models, the use of binary variables as indicator variables is introduced. In particular, the binary knapsack problem and the assignment problem are presented. Then, more generally, (mixed) integer linear programming problems are defined. In proposing some solution algorithms for these problems, reference is made to the cutting plane algorithm and the branch and bound algorithm. The concepts of valid inequality and continuous relaxation for a mixed integer problem are then introduced. The last topic of the course is nonlinear programming. With reference to the case of convex problems, the existence conditions and optimality conditions are introduced in both the unconstrained and constrained cases. Finally, Support Vector Machines are introduced as a tool of statistical learning theory and the formulation of the maximum margin linear separation problem as a convex quadratic optimization problem is proposed.
