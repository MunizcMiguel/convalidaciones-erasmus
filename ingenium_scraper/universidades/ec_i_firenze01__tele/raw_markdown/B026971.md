## Learning objectives

The Course provides the knowledge of the main Internet protocols, technologies and applications architectures, with a focus on the analysis and design phases. With reference to the Dublin Descriptors: 1. KNOWLEDGE AND UNDERSTANDING 1.1 Knowledge and understanding of the main aspects of the Internet, in terms of architectures, protocols and applications. 2. ABILITY TO APPLY KNOWLEDGE AND UNDERSTANDING 2.1 Ability to analyze and model protocol architectures. 2.2 Ability to design services and applications. 3. INDEPENDENCE OF JUDGMENT 3.1 Ability to critically discuss the specific technical literature and to apply it in the analysis and design phase. 4. COMMUNICATION SKILLS 4.1 Ability to clearly and rigorously explain the technical characteristics and properties of network architectures and applications. LEARNING ABILITY 5.1 Ability to independently find technical documentation (mainly standards) on network protocols and services.

## Extended programme

Introduction • Protocol stack: • Standard ISO-OSI and TCP/IP • Internet evolution Application Layer • Applications architectures: • Client->Server and Peer-to-Peer Models • Socket programming • Domain Name System: architecture and protocols • World Wide Web • HTTP: resource, architecture and protocols • HTML 5 (CSS) • Javascript • Mobile Web • Search Engines • Web 2.0 and social networking • REST paradigm and SOAP architecture Transport Layer • UDP: • features, • packet format; • TCP: • features; • packet format; • connection management; • flow and congestion control; • TCP evolution: Tahoe, Reno, New Reno, SACK, ECN flavor Internet QoS management: • RTP, RTPC e SIP Network Layer • Routing and Forwarding • IPv4, ARP, DHCP, ICMP, Traceroute • IPv6, NAT • Autonomous Systems, ISP e Border Router: RIP, OSPF, BGP protocols
