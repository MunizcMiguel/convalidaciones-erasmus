## Lernziele (learning outcomes)

At the end of this course, students will be able to:
-  understand user-space software vulnerability types and protection mechanisms
-  understand how to write code to reduce the risk of vulnerabilities and apply defensive programming
techniques
-  identify new software vulnerabilities and evaluate their impact
-  demonstrate the existence of a vulnerability, for example, by developing proof of concept exploits

## Inhalt

The course covers the area of introductory software security, vulnerability discovery, and vulnerability verification,
focusing on:
-  Assembly and Disassembly, Shellcode
-  Binary Reverse Engineering and Debugging
-  Memory and Type Safety/Errors
-  Stack-based Buffer Overflows
-  Heap Attacks
-  Information Leakage
-  Format String Vulnerabilities
-  Code Re-use Attacks
-  Types and Type Safety
-  Race Conditions
