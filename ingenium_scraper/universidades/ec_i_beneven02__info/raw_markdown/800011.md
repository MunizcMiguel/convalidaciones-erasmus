## Contents

The course spans one academic year and is divided into two modules, organized as follows: Module 1 (first semester): - Fundamentals of Object-Oriented Programming (OOP) - Introduction to the Object-Oriented paradigm: Concepts of class, object, state, behavior, and message passing; the principles of encapsulation and information hiding. - Object-Oriented Modeling: Introduction to UML class diagrams (syntax, as well as association, aggregation, composition, and inheritance relationships). - Inheritance and Polymorphism: Class extension, method overriding and overloading, subtype polymorphism, and the dynamics of late binding. - Abstraction and Code Management: Abstract classes and interfaces. - Generic Data Types: Type parameterization; definition and use of generic classes, interfaces, and methods, parameter constraints and wildcards, type safety, and code reusability. - Abstract Data Types (ADTs) and Collections: Design, usage, and underlying data structures for Lists, Sets, Maps, Trees, and Hash Tables. - Software Robustness: Exception handling, types of exceptions (checked/unchecked), the try-catch-finally mechanism, and the creation of custom exceptions. Module 2 (second semester): - I/O Fundamentals: Byte streams and character streams (InputStream, OutputStream, Reader, and Writer classes). - File Reading and Writing: Using buffers for I/O efficiency (BufferedReader, BufferedWriter) and managing resources via the try-with-resources syntax. - Advanced File and Path Manipulation: Handling text and binary files, overview of packages for file system management (ava.io` and java.nio.file). - Object serialization: The concept of persistence, the Serializable interface, and object streams (ObjectInputStream / ObjectOutputStream). - Recursion: Fundamental principles, base and recursive cases, comparison with the iterative approach, and application to data structures. - Introduction to multi-paradigm languages: Transitioning between paradigms and the features of the Python language that support various programming styles. - Fundamentals of functional programming: The concept of functions as first-class citizens, immutability, and side effects avoidance. - Lambda expressions: Syntax, closures, and anonymous functions. - Higher-order functions: Passing and returning functions as arguments (e.g., map, filter, reduce). - Generative functions: Generators, iterators, and lazy evaluation. - Streams: Processing data streams and performing sequential or parallel operations on collections.

## Learning objectives

The course aims to provide students who have already acquired basic programming knowledge (e.g., procedural programming in C) with the skills required for software design and development according to advanced paradigms, such as the object-oriented paradigm and the functional paradigm. EXPECTED LEARNING OUTCOMES: - Knowledge and understanding: Upon completion of the course, the student can: understand the fundamental principles and concepts of object-oriented programming (OOP) and functional programming; know the syntax and features of Java (for object-oriented programming) and Python (as a multi-paradigm language); and read and understand API documentation as well as third-party commented source code. - Applying knowledge and understanding: The student will be able to apply program modeling according to the object-oriented programming paradigm using UML. Furthermore, the student will be able to write and comment Java code, both by extending existing classes and creating new ones. The student will acquire skills to develop Python applications using a multi-paradigm approach. Finally, the student will be able to apply techniques for identifying and resolving errors both at compile time and runtime (debugging). - Making judgments: The student will be able to evaluate and interpret different programming techniques and paradigms (procedural, object-oriented, functional), identifying the most suitable approach to solve a given computational problem. Additionally, they will be able to critically evaluate the quality, readability, and efficiency of their own and others' source code. - Communication skills: The student will be able to communicate concepts, design choices, and developed IT solutions using appropriate and internationally recognized technical terminology. - Learning skills: The student will develop the ability to independently consult and explore the official documentation of languages and libraries/APIs. At the same time, the student will be able to autonomously develop the skills necessary to learn new programming languages or frameworks related to the studied paradigms.

## Prerequisites

In order to achieve the expected learning outcomes, students must have knowledge of procedural programming and know how to program using the C programming language. Furthermore, to take the final examination, students must have previously passed the Programming 1 exam.

## Teaching methods

In line with the total number of teaching hours for the course, the educational activity is indicatively broken down as follows: - Lectures (approx. 70% of total hours): held in the classroom with the aid of a video projector and multimedia presentations for the introduction and theoretical explanation of programming concepts and paradigms. - Practical sessions and laboratory activities (approx. 30% of total hours): practical lessons aimed at using Integrated Development Environments (IDEs) and dedicated to the design, implementation, and debugging of software programs using the different paradigms covered. Attending the course is not mandatory, but participation in educational activities is strongly recommended. On the University e-learning platform (Handy), teaching materials and guidelines for individual study are available, accessible also to working students and non-attending students. Students with valid certifications for SLD (Specific Learning Disabilities), disabilities, or other special educational needs are invited to contact the professor or the Department/Degree Program disability contact person at the beginning of the course, in order to agree on any teaching arrangements that, while respecting the course's objectives, take into account individual learning needs.

## Assessment methods

The final examination consists of a practical computer-based test and an oral interview, aimed at assessing knowledge of the topics included in the syllabus and, more generally, the achievement of the training objectives. The evaluation elements are: (i) the quality of content and the formal/logical correctness of the developed code; (ii) the appropriate use of technical terminology and overall expressive ability; (iv) the capacity to connect the topics included in the program; (v) the ability to provide practical and applied examples. In the learning assessment, the tests taken by the student contribute to the final grade according to the following percentage indicators: - Practical computer-based test (50% of the overall evaluation): development of programs using the Java and Python programming languages, aimed at verifying the skills acquired in the practical application of the learned topics. - Oral interview (50% of the overall evaluation): discussion on the topics covered during the course and solving exercises, aimed at assessing the level of knowledge and conceptual mastery achieved. Students with valid certifications for SLD (Specific Learning Disabilities), disabilities, or other special educational needs are invited to contact the lecturer or the Department/Degree Course disability representative prior to the assessment, in order to agree on any examination arrangements that, while respecting the learning objectives of the course, take into account individual learning needs. Note: Intermediate assessments are scheduled exclusively for attending students. These tests consist of computer-based exercises designed to evaluate skills related to object-oriented programming using Java and multi-paradigm programming using Python. Successfully passing both intermediate tests waives the requirement to take the practical computer-based exam. The results of the intermediate tests contribute to the final overall grade (with a weight of 50% each), provided that the final assessment (or the completion of the exam) takes place by the last available exam session of the summer period.
