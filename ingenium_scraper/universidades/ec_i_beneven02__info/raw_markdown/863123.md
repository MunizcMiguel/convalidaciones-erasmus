## Contents

- Pervasive computing: definitions, application scenarios, enabling technologies. - Main operating systems in the mobile and embedded fields. Introduction to Android. - Development, debugging toolchain. Version control and continuous integration, devops for mobile, wearable and embedded systems. - Design of graphic interfaces on mobile platforms. - Android core components. Background processes and services. - Android UI: activities, layouts, views. Interprocess communication in android: Intents and filters. - Android Security. - Microservices and Services integration issues. (annotated examples for the Java platform). - Management of resources (cpu, network, peripherals), sensors (gps, inertial sensors, specific sensors) and software services (telephony, mail, etc.) - Application life cycle. Deploy an application. Introduction to the android market. - Development, debugging toolchain. - Toolchain development, debugging.

## Reference texts

The course includes the use of publicly available online materials (resources for the developers of the platforms used) and handouts provided by the teacher. The materials will be provided during the lectures. Below are some reference texts for those interested in learning more about the topics covered: - Android Programming, Bill Phillips, Chris Stewart, et. to the. - Operating Systems Foundations with Linux on the Raspberry Pi - Kotlin Programming by Example, Iyanu Adelekan - Building Microservices: Designing Fine-Grained Systems by Sam Newman - RESTful Web Services, Leonard Richardson, Sam Ruby - Restlet in Action, Jerome Louvel, et. al.

## Learning objectives

The course aims to introduce the student to the problems of designing and implementing applications for mobile devices, and to the related methodological solutions. These problems and the relative solutions will be illustrated both on a methodological level with an approach independent of the specific technologies and illustrated using a set of real platforms. In particular Android will be used for the management of devices or sensors. At the end of the course, the student will be able to design and implement distributed applications involving mobile devices of various kinds: from the user interface of interactive devices, to application logic, from connection to cloud services, to sensor control, up to packaging. and the deployment of mobile applications on stores available online.

## Prerequisites

The courses of "Computer Architecture" and "Programming 2" are prerequisites. A good command of programming techniques and of at least one object-oriented language (e.g. Java, Kotlin, C ++, Python) is also required. The reference language of the course is Java / Kotlin. Basic knowledge of networked and distributed application programming techniques (both network level and application protocols) are useful and will in any case be referred to as necessary.

## Teaching methods

The course is structured in lectures and assisted exercises. The exercises are aimed at the practical application of the theoretical and methodological knowledge developed during the lectures. The reference language of the exercises is Java (or Kotlin optionally). During the course, students will design and build a complete application from requirements specifications to deployment starting from specifications agreed with the teacher. The material produced will be discussed at the examination.

## Other information

During the course, the Handy and Google Classroom/Drive platforms will be used to share materials and manage content and exams. Further information will be provided during the first lesson.

## Assessment methods

The exam consists in the presentation of the project work agreed and developed by the student to verify the ability to solve real problems even if they are smaller. After the discussion of the project work follows an oral interview aimed at ascertaining knowledge of the topics covered in the lectures.
