# Análise e Modelação de Sistemas (Mod112)

## Informação geral

- **Licenciatura:** Licenciatura em Engenharia Informática e de Computadores - Alameda (LEIC-A)
- **Ano / Semestre:** 3 / 5
- **ECTS:** 6
- **Período lectivo:** 1º Semestre 2025/2026

## Programa

* Introdução à arquitetura empresarial

* Modelação de arquiteturas empresariais com a linguagem ArchiMate

* Introdução à modelação de processos de negócio

* Modelação de processos de negócio com a linguagem BPMN

* Introdução à engª de requisitos

* Processo e técnicas de desenvolvimento de requisitos

* Processo e técnicas de gestão de requisitos

* Introdução à modelação de sistemas de informação

* Modelação de sistemas de informação com a linguagem UML

* Modelação de sistemas ciber-físicos e físicos com a linguagem SysML

* Especificação de Requisitos: Objetivos, Cenários, Casos de utilização, Histórias, Requisitos Não-Funcionais, Restrições

## Método de avaliação

**Nota Final**

- NF = 60% NT + 40% NP

- NT = Nota Teórica

- NP = Nota Prática

-------------------------------------------------

#### **Regime de Época Normal**

- **Nota Teórica**

- **Nota de Projeto**

-------------------------------------------------

#### **Regime de Trabalhador-Estudante**

- Podem obter NT por NE ou por NC

- Podem obter NP em grupo normal, ou fazer projeto individual (neste caso **contactar o mais tardar até ao fim da primeira semana de aulas o Prof. Responsável para os termos do projeto como trabalhador-estudante**)

-------------------------------------------------

#### **Regime de Época Especial**

- NT = Nota de Exame de Época Especial

- NP = Nota de Projeto (aluno pode reusar nota **se fez o projeto em Época Normal; caso contrário, contactar o mais cedo possível o Prof. Responsável para os termos do projeto neste contexto de Época Especial**)
