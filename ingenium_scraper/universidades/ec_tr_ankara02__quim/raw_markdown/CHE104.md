### Objectives of the Course

To introduce the basic concepts of the programming language, to provide the algorithm and programming logic, and to gain the ability to write programs using the programming development environment and the ability to use programming languages to solve chemical engineering problems effectively.

### Course Content

Computer systems, operating systems, Problem solving, algorithm development and flow diagrams, Basic concepts of programming, Data types, Mathematical operations and functions, Program control commands, Cycle structures, Input-output operations, Subroutines, Pointers
