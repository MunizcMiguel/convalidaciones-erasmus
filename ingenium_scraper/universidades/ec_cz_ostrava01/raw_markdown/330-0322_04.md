# MathCad

## Type of Course Unit

Choice-compulsory

## Level of Course Unit

First Cycle

## Semester when the Course Unit is delivered

Winter, Summer Semester

## Mode of Delivery

Face-to-face

## Language of Instruction

English

## Prerequisites and Co-Requisites

Course succeeds to compulsory courses of previous semester

## Summary

Information about basic methods for solution mathematical problems using

programme Mathcad.

Numerical formula and progression solution.

Linear and non-linear equation solutions and their systems.

User functions definition, indexed numerical field. Graph creating. Vector and

Matrix operations, symbolic processes, basic programming.

## Learning Outcomes of the Course Unit

Student will be able to use programme Mathcad for soulution base mathematical problems. Student will use programme for solution of the professional problems using "User Guide" and "Help".

## Course Contents

Simple calculation, editation of the solution.

Using units, contants. Text and mathmatical relations in the documents,

vectors, matrix, graphs.
