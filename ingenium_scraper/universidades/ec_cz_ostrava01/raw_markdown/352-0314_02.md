# Process Visualization

## Type of Course Unit

Choice-compulsory

## Level of Course Unit

First Cycle

## Semester when the Course Unit is delivered

Winter Semester

## Mode of Delivery

Face-to-face

## Language of Instruction

Czech

## Prerequisites and Co-Requisites

Course succeeds to compulsory courses of previous semester

## Summary

This course deals with process visualization, data monitoring and acquisition

for supervisory control. Students learn how to develop SCADA/HMI

applications for monitoring technological processes. SCADA/HMI products used for implementing methods for visualization during this course are InTouch from Wonderware. Examples are given for communication and data acquisition for visualization on operator screens.

## Learning Outcomes of the Course Unit

This course deals with process visualization, data monitoring and acquisition

for supervisory control. The main objective of this subject is an introduction to definitions, descriptions and parts of operator environment of supervizory control systems and data acquisition and the use of tools in development software for data visualization.

## Course Contents

Topics:

1. Development environment - configuration of objects, object libraries, symbols and smart objects.

2. The database of monitored variables - data types.

3. Alarms - Configuration screen objects, scripts.

4. Trends - real and historical - tools, filtration in the historical data.

5. Communication with external data provider application environment.

6. Access to process data, the hierarchy of competencies and workstations
