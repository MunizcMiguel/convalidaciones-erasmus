### Objectives of the Course

It is aimed that the students are able to have information about sensors, transducers and actuators that are used in mechatronics systems. They are also expected to have laboratory experiences about using such mechatronics components. Giving basic level programming knowledge that is used to make contact between mechatronics components and computers is the another main objective of this course.

### Course Content

The contents of this course; The basic components which are used in mechatronics systems. The basic level microprocessors. Itroduction to basic level microprocessor programming. Programming knowledge that is to be used for simulations. The laboratory studies conducted for using mechatronics components.
