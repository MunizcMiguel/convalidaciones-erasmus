### Objectives of the Course

It is aimed to give a detailed training on types, hardware and software of CNC machine tools, which are widely used in the industry, computer aided manufacturing.

### Course Content

CNC and CAM system functions and application areas, Machine tool structure and parts, Machine coordinate systems, CNC lathe and CNC milling machine programming.

### Course Methods and Techniques

Stage 1: Oral lecture and written (Visualization with the help of a classroom board and digital presentation.)

Stage 2: Applying what has been learned on the computer

Stage 3: Applying the lessons on the CNC machine

## Course Learning Outcomes: Upon the successful completion of this course, students will be able to:

| No | Learning Outcomes |
|---|---|
| 1 | Knows NC, CNC and CAD/CAM functions, application areas, CNC machine tool types and working principles in computer-aided manufacturing. |
| 2 | By obtaining detailed information about the structure and parts of CNC machines, the student will have preliminary information about the design and production of a new CNC machine. |
| 3 | At the end of this course, students will be able to control the production process with an analytical program for the production of workpieces of any geometry and to prepare the machine for production. |
