# Binary Logic & Digital Functions

Module code: MSTEE11
Duration: 30 h

## Objectives

- At the end of this module, students will be able to: analyse and design
- digital functions

## Topics

- Basic concepts of probability:
- Number representation
- Fundamentals of Boolean algebra
- Construction of elementary gates
- Circuits developed from combinatory logic (comparator, decoder
- and demultiplexer)
- Introduction to sequential logic and its basic components (D, RS,
- RSH, and JK flip flop circuits)
- Registers and counters
- Designing and creating a sequential system
