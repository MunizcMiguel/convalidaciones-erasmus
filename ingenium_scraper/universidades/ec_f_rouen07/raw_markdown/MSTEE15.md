# LabView

Module code: MSTEE15
Duration: 30 h

## Objectives

- Design a program with LabVIEW for an electrocardiogram that
- monitors real and “noisy” data.  This program must:
- respect design standards
- use standard programming and signal processing tools seen in the
- 2nd year
- The application must respect standard LabVIEW practices (taken
- from the Certified LabVIEW Developer (CLD) test) and use a modular
- and evolving architecture

## Topics

- Fundamental programming notions in LabVIEW
- LabVIEW programming
- Creating an interface
- Learning good LabVIEW practices for form and structure in
- programming
