# Python Programming & Image Treatments

Module code: MSTSEE36
Duration: 30 h

## Objectives

- The Python language is today, one of the most useful programming tool
- for engineers and is used in several applicative areas including embedded
- systems. The objective of this elective is to understand the environment,
- the tools and the scope of this language.
