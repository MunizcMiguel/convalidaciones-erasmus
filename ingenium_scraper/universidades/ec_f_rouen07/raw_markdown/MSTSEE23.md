# Communication Busses

Module code: MSTSEE23
Duration: 30 h

## Objectives

- At the end of this module, students will be able to:
- Use the most widely used communication busses in the field of
- embedded processors
- Understand technical specifications

## Topics

- RS-485
- I2C BUS, SPI BUS
- CAN BUS
- ARINC bus
