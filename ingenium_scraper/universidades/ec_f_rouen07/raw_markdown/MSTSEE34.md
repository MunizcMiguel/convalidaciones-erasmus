# DSP Processors

Module code: MSTSEE34
Duration: 20 h

## Objectives

- At the end of this module, students will:
- Be familiar with the main DSP (digital signal processing) algorithms
- and their impact on DSP architecture

## Topics

- Sampling, convolution
- Linear filtering
- Fourier transforms
- STM32F407VG ARM based processor
