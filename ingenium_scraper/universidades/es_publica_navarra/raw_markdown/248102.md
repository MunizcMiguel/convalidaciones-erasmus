## Módulo/Materia

Módulo de Formación Básica
Materia Informática

## Descripción/Contenidos

Introducción: Estructura física y lógica de un ordenador. Sistemas operativos.
Introducción a la programación: Tipos de datos, estructuras de control y modularización.
Programas de aplicación: hoja de cálculo, bases de datos, planificación de proyectos, usos básicos de Internet.

## Competencias genéricas

Las competencias genéricas que un alumno debería adquirir en esta asignatura son:

- CG3. Conocimiento en materias básicas y tecnológicas, que les capacite para el aprendizaje de nuevos métodos y teorías, y les dote de versatilidad para adaptarse a nuevas situaciones.

- CG4. Capacidad de resolver problemas con iniciativa, toma de decisiones, creatividad, razonamiento crítico y de comunicar y transmitir conocimientos, habilidades y destrezas en el campo de la Ingeniería Industrial en la tecnología específica Mecánica.

## Competencias específicas

Las competencias específicas que un alumno debería adquirir en esta asignatura son:

- CFB3. Poseer conocimientos básicos sobre el uso y programación de los ordenadores, sistemas operativos, bases de datos y programas informáticos con aplicación en ingeniería.

## Resultados aprendizaje

R1. Identificar los distintos componentes del sistema físico y lógico del ordenador

R2. Comprender la función de un sistema operativo como gestor del sistema físico del ordenador

R3. Manejar los sistemas operativos más comunes

R4. Utilizar herramientas de edición, compilación y ejecución para desarrollar programas.

R5. Utilizar las diferentes estructuras de control para desarrollar programas

R6. Utilizar las diferentes estructuras de datos para desarrollar programas

R7. Realizar pruebas para validar los programas desarrollados

R8. Diseñar una base de datos sencilla

R9. Realizar consultas sobre una base de datos

R10. Utilizar una hoja de cálculo

R11. Conocer herramientas informáticas para planificar proyectos de ingeniería

R12. Comprender el paradigma de la WWW
