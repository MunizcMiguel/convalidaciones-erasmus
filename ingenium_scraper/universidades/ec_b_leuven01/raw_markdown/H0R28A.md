# AI for Biomedical Data Analysis

Studiepunten (ECTS): 6

## Course objectives

The student knows the foundations and basic concepts of biomedical data analysis and can apply them in the domain of biomedical signal and image processing. More specifically:
The student knows the basic concepts of statistics and machine learning.
The student knows how to correctly select data science methodologies to apply to problems in biomedical engineering.
The student can call the methods in Python and correctly apply them to practical problems in biomedical signal and image processing.

## Content

This course covers the fundamentals and basic concepts of data science and machine learning, and combines concepts from statistics, data analysis, and machine learning, with applications to biomedical signal and image processing. These topics are developed in modules as follows. Each module covers one or more time slots.
Module 1: Introduction to biomedical signals (ECG, EEG, EMG, accelerometry, bioimpedance,…) and images (X-ray, CT, MRI, PET, …)
Module 2: Estimation theory with applications in biomedical data analysis:
Fisher information,
Cramér-Rao lower bound, U-statistics
bootstrapping,
Maximum Likelihood,
Module 3: Hypothesis tests for machine learning and biostatistics:
Concepts
- P-values
Wilcoxon test and permutation tests
Rank-tests such as the Mann-Whitney U test, Kruskal-Wallis and other non-parametric tests
Bonferroni correction in the case of multiple comparisons
Goodness-of-fit tests
Power analysis
Module 4: Classic machine learning methods
Nearest neighbors
Decision trees
Bias-variance decomposition
Module 5: Linear models and optimization
Logistic regression
Tikhonov regularization
Gradient descent
Learning rate, training curves
Stochastic gradient descent
Metrics for classification and regression
Module 6: Neural networks
Multi-layer perceptrons
Convolutional networks
Backpropagation
Deep learning

## Content

Exercise sessions are planned on the following topics:
Estimation theory
(Non)parametric hypothesis tests and variance analysis
Classification and cluster analysis
Biomedical image analysis
Time-series analysis
Machine learning challenge
In each exercise session, the student will learn the correct use of the tests and/or covered methods, how to call the tests and/or methods in Python and to correctly apply them to practical problems in biomedical signal and image analysis.
