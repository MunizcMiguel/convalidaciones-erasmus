# Introduction to Finite Elements for Mechanical Systems

Studiepunten (ECTS): 3

## Course objectives

Knowledge: basic concepts of finite elements for bar constructions in static applications
Skills: the student can fully compile a matrix formulation, code in Matlab/Python, carry out a complete analysis, and interpret results
Understanding: demonstrate the modular nature of the method and make connections to other courses in the curriculum where these points are addressed
Secondary objectives: mathematical modeling of a continuous system with discrete degrees of freedom, coding of a problem in a matrix formulation

## Content

Context and fundamental concepts of discretization
Composition of system matrices
- Based on physical principles (for 2D problems)
- Stiffness matrix of a bar element (truss structures)
- Stiffness matrix of a beam element
- Derived from energy statements in displacement formulation
- System equations
- Element stiffness matrix
- System stiffness matrix
- Coordinate transformations (for 3D problems)
- Properties of the system matrix
Definition of boundary conditions and loads
Solution of the system of equations
Postprocessing of the results
Basic non-linear analysis (geometric non-linearity)
Outlook on the extension from 1D elements to 2D and 3D elements

## Content

The students independently formulate a matrix model using Matlab/Python in several sessions with gradually increasing complexity:
• Truss structure (with hinged nodes)
• Straight beam structure with orthogonal elements
• Planar structure with inclined/curved beams in 2D
• Bar structure in 3D
• Comparison of the previous exercises with an analysis in commercial Finite Element (FE) software.
