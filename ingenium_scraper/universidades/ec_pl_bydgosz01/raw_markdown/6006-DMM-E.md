# Data Mining Methods

## Syllabus (original text)

COURSE DESCRIPTION
Title of the course: Data Mining Methods
Lecture hours: 15
Study period: Summer and/or winter semester (available in both semesters)*
(summer/winter semester)
Number of credits: 2 ECTS credits
Assessment methods: The final assessment consists in verifying the assumed learning outcomes by
assessing knowledge and skills demonstrated during the performance of
problem tasks.
The result of the student's work will be reports.
Language of instruction: english
Prerequisites: not applicable
Course content: Theory and practice on:
 Initial data preparation for data mining processes.
 Introduction to classification problems, division of the data set into training
and testing sets.
 Rule classifiers, simple tree classifiers, decision tree induction methods.
 Classifiers in the form of neural networks.
 Discovery of association rules and their algorithms. Algorithms for finding
frequent sets and associations, basket analysis.
 Naive Bayes classifier.
 kNN classifier.
Tools used in the laboratory: Statistica Data Miner, Excel
Learning outcomes: Knowledge: student
W1. has detailed knowledge of data mining and data processing (K_W08),
W2. knows the methods, techniques and tools used in solving engineering tasks
in the area of data mining (K_W12),
Skills: student
U1. Can obtain information from literature, databases and other sources
necessary to solve data mining tasks (K_U01).
U2. Can assess, at a basic level, the usefulness of routine IT methods and tools
and select and apply the appropriate method and tools to solve data mining
tasks (K_U28).
