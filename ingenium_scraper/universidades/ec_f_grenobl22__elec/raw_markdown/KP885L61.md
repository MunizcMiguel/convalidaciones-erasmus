# UE Informatique embarquée avancée

- **Niveau d'étude** : Bac +3
- **ECTS** : 3 crédits
- **Composante** : UFR Physique, Ingénierie, Terre, Environnement, Mécanique (PhITEM)
- **Période de l'année** : Printemps (janv. à avril/mai)

## Description

Cette UE, dans le prolongement de l’UE informatique embarquée du semestre 5, permet d’approfondir l’étude d’un microcontrôleur basé sur un cœur Cortex-M4. Le Cours/TD et les TP (24h) permettent d’étudier le fonctionnement du microcontrôleur sur interruptions et d’aborder les modes plus avancés de certains périphériques (CAN, DMA, Timers, I2C). De nombreuses applications de travaux pratiques sont réalisée sur un robot mobile.

### Heures d'enseignement

- TD 4,5h
- TP 24h

### Période

Semestre 6
