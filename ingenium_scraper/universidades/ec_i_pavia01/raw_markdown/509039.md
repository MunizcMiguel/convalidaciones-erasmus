# ALGORITHMS AND DATA STRUCTURES (509039)

## General information

- **Degree programme:** ELECTRONIC AND COMPUTER ENGINEERING (06413)
- **Curriculum:** Percorso INFORMATICA
- **Year of study:** 3
- **Academic year of delivery:** 2026/2027
- **Period:** 2nd semester
- **ECTS:** 6
- **Hours:** Lecture: 45
- **Scientific sector (SSD):** ING-INF/05
- **Type of activity:** Non-core
- **Area:** Analogous or integrating activities
- **Exam type:** Written exam
- **Grading:** Final Grade
- **Attendance:** Not mandatory
- **Teaching methods:** Lecture

## Language

Italian

## Prerequisites

Knowledge of computer and networks hardware/software architecture.  
Knowledge of a programming language.

## Learning objectives

Knowledge of classical algorithms and data structures.  
Ability to analize and design application-specific algorithms and data structures.

- Fundamentals  
Basic Programming Model  
Data Abstraction  
Bags, Queues and Stacks  
Analysis of Algorithms  
  
- Sorting  
Elementary Sorts  
Mergesort  
Quicksort  
Priority Queues  
  
- Searching  
Symbol Tables  
Binary Search Trees  
Balanced Search Trees  
Hash Tables  
  
- Graphs  
Undirected Graphs  
Directed Graphs  
Minimum Spanning Trees  
Shortest Paths  
  
- Strings  
String Sorts  
Tries  
Substring Search  
  
- Formal Languages  
  
- Data Protection Rules

## Teaching methods

Frontal, face-to-face lectures

## Reference texts

Data Structures and Algorithms in Python  
Pearson Ed.

Learning outcome will be verified through a written test. The candidate shall have to answer 4 open questions and to develop the execution trace of a given algorithm
