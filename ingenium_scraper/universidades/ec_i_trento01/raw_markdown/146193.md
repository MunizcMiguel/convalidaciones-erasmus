## Learning objectives

The course introduces the basics of kinematic modeling and kinematic control of open-chain robotic systems, focusing on the specific case of manipulator robots. At the end of the course, students will be able to:

- model the geometry of an open kinematic chain
- implement algorithms for calculating the position of the robot's end effector and its velocity
- control the robot in joint space
- control the Cartesian position and orientation of the robot's end effector
- plan different types of trajectories using polynomials
- solve the inverse geometry problem using Newton's method
- use ROS middleware to write modular software for controlling and planning the motion of a manipulator robot

## Prerequisites

Basics of linear algebra (matrices, vectors, matrix calculus, matrix inversions), analysis (derivatives), mechanics (linear and angular velocity, reference systems), procedural programming (variables, functions, loops).

## Contents

INTRODUCTION

- A Brief History of Robotics
- Overview of a robot’s functional units: sensors, actuators, mechanics
- Overview of the main topics in robotics: control, perception, estimation, planning
- Introduction to Python/ROS

MODELING

- Geometry: homogeneous matrix (review), direct kinematics via composition of homogeneous matrices, end-effector orientation (rotation matrix, Euler angles, angle-axis, quaternion)
- URDF files: reading a URDF file, visualizing the robot in a simulation environment, calculating the end-effector pose
- Differential kinematics: Jacobian (analytic and geometric), mapping RPY’s time derivatives to angular velocity

CONTROL IN JOINT SPACE

- Velocity/acceleration control in joint space with proportional-derivative feedback
- Planning reference trajectories using polynomials: constant-velocity trajectories, trajectories with zero initial and final velocities, trajectories with zero initial and final accelerations, minimum-time trajectories, curvilinear trajectories
- Inverse kinematics: uniqueness and existence of the solution, Newton’s method

CONTROL IN THE END-EFFECTOR SPACE

- Cartesian velocity control using the pseudo-inverse Jacobian
- Velocity control in null space, analysis of redundancy and singularities via the Jacobian matrix, singular value decomposition, damped least squares
- Velocity-level orientation control of the end-effector using the geometric Jacobian
- Partial pose control of the end-effector, control of a tool attached to the end-effector, pose error weighting, orientation interpolation

## Teaching methods

Classroom lessons will use blackboard, slides and Python notebooks, allowing theory to be interspersed with programming, with the aim of demonstrating the practical application of theory to a concrete example.

Laboratory lessons will focus on programming in Python to control small manipulator arms.

## Assessment methods

To pass the exam, students must take a written exam that tests both their understanding of the theory and their ability to apply the theory to solve practical robotics problems.

## Reference texts

The material provided by the instructor is sufficient for exam preparation. However, if anyone feels the need to study the topics in greater depth using a textbook, the following books may be used.

- Siciliano, B., Villani, L., Oriolo, G., & De Luca, A. (2025). Foundations of Robotics. Advanced Textbooks in Control and Signal Processing (available in English only).
- Siciliano, B., Sciavicco, L., Villani, L., & Oriolo, G. (2009). Robotics: modeling, planning, and control. London: Springer London (also available in Italian).
