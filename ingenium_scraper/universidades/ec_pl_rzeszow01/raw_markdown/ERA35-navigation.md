# Navigation

- ECTS: 5
- Source: Erasmus incoming course offer, Faculty of Mechanical Engineering and Aeronautics (2026), pp. 10-10

## Course description

Earth and geoid model. Position on the Earth, reference systems, circles, latitude and longitude. Great circles and rhumb lines, distances. The vector triangle, wind components. General navigation problems. Topographical maps, scales, charts. Earth magnetism. Direct indicating compass. Remote indicating compass. Gyroscopes. Inertial reference system (IRS), inertial navigation system (INS). Area navigation systems (RNAV). Global navigation satellite systems (GNSS: GPS, GLONASS) and augmentation systems (ABAS, GBAS, SBAS).
