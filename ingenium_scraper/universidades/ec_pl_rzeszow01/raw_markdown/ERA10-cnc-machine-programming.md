# CNC machine programming

- ECTS: 3
- Source: Erasmus incoming course offer, Faculty of Mechanical Engineering and Aeronautics (2026), pp. 3-3

## Course description

Basics of CNC machine tool construction: Characteristics of numerically controlled machine tools; Structure of numerical control in machine tools; Numerically controlled axes; Design variants of CNC machine tools; CNC numerical control systems; Machine bodies and guides; Drive units; Position and displacement measurement systems; Tool-changing devices. Basics of CNC machine tool programming: Activities involved in creating a control program; Methods of programming CNC machine tools: manual, automatic, and dialog programming; Fundamentals of manual programming based on ISO code, Structure of a control program; Subroutines and declaration of the dimensioning method. Programming functions related to tools and their dimensions. Parametric programming. Programming technological functions. Programming auxiliary functions.
