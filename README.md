# Portal de Convalidaciones ERASMUS · EPI Gijón (UNIOVI)

Herramienta interactiva para la consulta, simulación y planificación de acuerdos académicos (*Learning Agreements*) de movilidad internacional Erasmus+ para los estudiantes de la Escuela Politécnica de Ingeniería de Gijón (Universidad de Oviedo).

### ✨ Características Principales

1. **Matriz Interactiva de Equivalencias:**
   - Comparativa asignatura a asignatura con porcentajes de coincidencia temática y códigos oficiales.
   - Filtros avanzados por titulación, curso, semestre, carácter de asignatura y estado de convalidación.
2. **Simulador de Learning Agreement:**
   - Planificador en tiempo real para verificar el cumplimiento de créditos ECTS (mínimo 60 ECTS anuales / 30 ECTS semestrales).
   - Balance automático de idiomas de docencia (inglés vs. portugués / italiano / alemán).
3. **Cotejo de Guías Docentes:**
   - Visualización y comparación simultánea de competencias, temarios detallados y criterios y sistemas de evaluación oficiales entre UNIOVI y las universidades de destino.
4. **Descarga de Tablas Maestras:**
   - Exportación directa de las matrices completas en formato Microsoft Excel (`.xlsx`).
